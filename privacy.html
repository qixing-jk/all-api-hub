All API Hub 隐私政策

最后更新日期： 2026 年 10 月 17 日

简体中文 | English | 日本語

适用范围与开发者

本政策适用于 All API Hub 浏览器扩展及其卸载反馈页面。All API Hub 由 qixing-jk/all-api-hub 开源项目维护，下文的“我们”指项目开发者。您配置的 API 平台、同步服务和其他第三方服务由各自的运营者提供。

扩展会读取、使用和存储实现功能所需的用户数据，包括敏感认证信息。默认本地保存不代表没有数据处理。 账户凭据不会作为产品统计上传给我们；但执行账户操作时，扩展需要将认证信息发送给对应的服务。默认开启的产品统计和您主动提交的反馈会发送至 PostHog，供开发者分析。具体范围如下。

数据收集与使用

数据类别获取方式和内容用途
账户与认证信息您输入、导入或授权扩展从对应站点读取的服务地址、账户名称、用户 ID、邮箱（如站点返回）、API Key、访问/刷新令牌、登录会话和 Cookie；适用登录流程中您输入的登录信息识别和登录账户、请求账户状态、管理密钥及执行您配置的站点操作
账户状态与业务数据对应平台返回的余额、额度、模型、价格、用量/请求日志、签到状态和网站公告展示账户、余额历史、用量分析、模型比价、签到和公告等功能
内容与设置书签、备注、标签、排序、偏好、导入文件、管理站点配置、同步和通知渠道的地址与凭据保存配置、导入导出、站长管理、自动任务、备份同步和通知
功能相关的网页与输入内容在添加账号、Cookie 导入、网页 API 嗅探、兑换助手或 API 验证等功能中，按相应权限和操作读取的网页地址、相关页面内容、选定内容、剪贴板或您输入的验证内容提取站点/凭据信息、兑换或向选定 API 发送验证请求；不为建立浏览历史而持续记录您访问的所有页面
产品统计与反馈下文列明的功能事件、安装统计标识符、技术环境，以及您主动提交的卸载原因和说明衡量功能可靠性、排查兼容问题和理解用户反馈

数据处理由您使用的功能、授予的权限以及自动刷新、签到、同步和通知等设置决定。启用的后台任务可能在您未打开扩展界面时运行。API 验证的请求内容会发送到您选定的 API 服务，并可能继续由其上游模型服务处理。

产品统计与卸载反馈

产品统计

产品统计在配置了统计服务的发行版本中默认开启，使用 PostHog 接收和存储事件，开发者可在该项目中查看和分析。您可以在「设置」中关闭界面中称为“匿名产品统计”的选项，停止后续产品统计事件。

  • 扩展在本地生成并保存一个随机的安装统计 ID，随事件发送，用于关联同一安装的使用情况。它不是您的 API 平台用户 ID，也不要求姓名或邮箱，但它是可关联的持久标识符，不应理解为所有统计数据都无法关联到同一安装。关闭统计不会自动删除这个本地 ID 或已发送的数据。
  • 业务事件使用字段白名单，包含扩展版本、发行渠道、浏览器类型、界面语言、扩展入口、功能/操作标识、结果、错误类别、站点类型，以及耗时、数量或规模区间。用途仅为维护、保障和衡量扩展已披露功能的性能和可靠性。
  • 业务事件不附带账户 API Key、访问/刷新令牌、Cookie、认证请求头、账户名称、平台用户 ID、邮箱、用户配置的站点地址、备注、导入导出内容、原始错误堆栈或 API 请求/响应正文，也不发送精确余额、额度或用量。
  • 除业务字段外，统计 SDK 还可附带事件时间、浏览器、操作系统、设备/屏幕和扩展页面等技术上下文。统计服务还可能处理和保存 IP 地址、HTTP 请求元数据及由 IP 推导的大致地区信息；不能将业务字段过滤理解为网络层不处理这些信息。
  • 扩展关闭了自动页面浏览事件、自动交互捕获和会话录屏，不使用产品统计记录您在其他网站上的完整浏览历史。

卸载反馈

卸载时，浏览器可能打开我们的卸载反馈页面。页面地址携带扩展版本、安装天数和语言；仅在统计开启时附带安装统计 ID，并发送页面打开事件，以关联卸载前的使用情况。统计关闭时不携带该 ID，也不发送该页面打开事件；但加载页面仍会向网站托管服务发出网络请求。

选择原因并点击提交后，您选择的原因、主动填写的说明（最多 500 个字符）和上述版本等上下文会发送到同一个 PostHog 项目，供开发者查看。即使已关闭产品统计，主动提交反馈仍会发送这些内容，但不关联之前的安装统计 ID。请勿在说明中填写密码、API Key 或其他敏感信息。

数据存储与安全

  • 本地数据： 账户、凭据、偏好和历史等默认保存在当前浏览器配置文件的扩展本地存储或本地数据库中。浏览器存储隔离不等于扩展对所有本地数据进行了额外加密；可访问设备或浏览器配置文件的人可能读取这些数据。
  • 本地导出： 您导出的 JSON 文件、复制到剪贴板的配置及分享快照由您控制。备份或配置可能包含凭据，请在分享前检查内容并妥善保存。
  • WebDAV（可选）： 按选定的同步范围，将备份发送到您配置的服务器，使用您提供的用户名/密码认证。备份可能包含账户凭据；WebDAV 备份加密取决于您是否启用相应设置。请使用 HTTPS；对于用户自行配置的 HTTP 地址，不能承诺传输已加密。
  • GitHub Secret Gist（可选）： 使用您提供的 GitHub Token 调用 GitHub API；上传前在本机使用您设置的密码进行 AES-256-GCM 加密。GitHub 接收认证 Token 和加密备份。Gist Token、Gist ID 和加密密码不进入手动 JSON 导出。Secret Gist 表示“不公开列出”，不等于只有您能访问链接。详见云同步说明。
  • 统计与反馈： 保存在配置的 PostHog 项目中，由 PostHog 提供服务，开发者可访问。其处理还受 PostHog 隐私政策及适用服务条款约束。

我们不运营用于集中保存您账户凭据的账户管理服务器。请保护设备、备份、同步密码及第三方账户；没有任何存储或传输方式可以保证绝对安全。

数据共享与接收方

我们不出售或出租用户数据，不将其用于个性化广告或跨网站广告追踪。数据仅为本政策说明的功能及处理流程传递给以下接收方：

接收方何时发送、发送什么
您添加或选择的 API 平台、管理站点及其相关认证/上游服务账户请求、登录、刷新、签到、密钥/模型管理、导入到管理站点或 API 验证时，发送所需的认证信息、操作参数和验证内容；并读取结果
您配置的 WebDAV 服务运营者；选择 Gist 时的 GitHub您执行备份或启用自动同步时，接收相应服务的认证信息以及备份内容；加密规则见上文
您选择的导出工具或应用您执行导出、复制或应用跳转时，接收所选服务地址、密钥和相关配置，例如 Cherry Studio、CC Switch 等；具体目标由您的操作决定
您启用的通知服务Telegram、钉钉、飞书、企业微信、ntfy 或自定义 Webhook 接收相应认证/路由信息及任务通知标题和正文，可能包括任务结果、站点或账户相关信息；浏览器通知由本机浏览器处理
PostHog 与项目开发者统计开启时接收上述产品事件；您主动提交时接收卸载反馈
GitHub、LDOH（ldoh.105117.xyz）及您打开的外部网站获取更新信息、项目公告或公开站点索引时，服务接收常规网络请求信息；LDOH 索引匹配在本机进行，点击站点查找链接时会向目标页面传递站点主机名作为搜索条件
文档与卸载页面的 GitHub Pages 托管服务及页面请求经过的 CDN 服务您访问页面时接收 IP 地址、请求地址（含查询参数）、浏览器请求头等常规网络信息，用于交付页面和服务运行

第三方服务可能在您所在国家或地区以外处理数据，其保存、安全和删除规则由各自政策及您的配置决定。您向我们提交支持请求或公开 GitHub Issue 时，开发者和相应平台也会接收您主动提供的信息；公开 Issue 对他人可见。

保存期限、删除与您的选择

  • 账户和设置： 保留在本地，直到您修改、删除相应条目或清除扩展数据。余额历史和用量历史按各自功能的保留设置清理。删除本地账户不会注销对应平台账户，也不会自动撤销已发行的 API Key。
  • 卸载： 浏览器通常在卸载时移除该扩展的本地数据；独立导出文件、剪贴板内容、其他设备、远端备份和第三方服务中的数据不会因此自动删除。
  • 远端副本： 停用自动同步可停止后续定时同步，但不会删除 WebDAV/Gist 中已有备份。需要在对应服务中删除备份及其历史版本，并视需要撤销 Token；还应检查其他同步设备，避免再次上传。
  • 产品统计与反馈： 关闭统计或卸载不等于删除已发送的事件。扩展不提供远端事件自动到期删除或一键清除功能；已发送的事件和反馈保留在 PostHog 项目中，直至在项目中删除，或适用的服务保留设置将其清除；不会因为关闭统计或卸载而自动到期。您可通过下方渠道请求查询或删除可定位的记录；没有可关联标识的信息可能无法准确定位到个人。
  • 权限和后台任务： 您可以在浏览器中撤销可选权限，在扩展中关闭自动刷新、签到、同步或通知；也可停止使用并卸载扩展。

如需查询、更正或删除我们可访问的统计或反馈数据，请先联系维护者说明请求类型，不要公开提交凭据。必要时我们会与您确认定位记录所需的信息。

Chrome Web Store 用户数据政策

All API Hub 对通过浏览器 API 获取的用户数据的使用和传输遵守 Chrome Web Store 用户数据政策，包括 Limited Use 要求：仅为提供或改进已披露的单一用途和面向用户的功能使用数据；不将其用于个性化广告、不出售给数据经纪商、不用于信用评估或借贷。除用户明确同意、必要的安全调查、法律要求，或为内部运营使用已汇总和去标识化的数据等政策允许的情形外，不允许人工读取此类数据。

政策更新与联系

我们会在本页更新政策及“最后更新日期”。需要额外披露或同意的数据处理变更，将按适用要求在产品中说明；本政策的更新本身不代替所需的授权。

如有隐私问题或数据请求，请通过 GitHub 项目维护者或项目 Issue联系。Issue 是公开的，请勿附上 API Key、密码、完整备份或敏感个人信息；需要非公开处理时，请先询问维护者可用的私密沟通渠道。
