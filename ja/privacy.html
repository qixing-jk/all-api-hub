All API Hub プライバシーポリシー

最終更新日： 2026 年 10 月 17 日

简体中文 | English | 日本語

適用範囲と開発者

本ポリシーは All API Hub ブラウザー拡張機能とアンインストール時のフィードバックページに適用されます。All API Hub は qixing-jk/all-api-hub オープンソースプロジェクトが保守しています。「当方」はプロジェクト開発者を指します。設定された API プラットフォーム、同期サービスなどは、それぞれの運営者が提供します。

本拡張機能は、機密性のある認証情報を含め、機能の提供に必要なユーザーデータにアクセスし、利用・保存します。ローカル保存であってもデータ処理に該当します。 アカウントの認証情報を製品統計として当方へ送信することはありません。ただし、アカウント操作では対応するサービスに認証情報を送信します。初期状態で有効な製品統計と、ユーザーが送信したフィードバックは、開発者による分析のため PostHog に送られます。

製品統計とアンインストール時のフィードバック

製品統計

統計サービスが設定された配布版では、製品統計は初期状態で有効です。PostHog がイベントを受信・保存し、開発者がプロジェクト内で閲覧・分析します。「設定」の「匿名製品統計」に相当する項目を無効にすると、その後の製品統計イベントの送信を停止できます。

  • 拡張機能はランダムなインストール統計 ID を生成してローカルに保存し、イベントとともに送信して同じインストールの利用状況を関連付けます。API プラットフォームのユーザー ID ではなく、氏名やメールアドレスも必要としません。ただし持続的に関連付け可能な識別子であり、「匿名」は同一インストールのイベントを関連付けられないという意味ではありません。無効化しても、このローカル ID や送信済みデータは自動削除されません。
  • 業務イベントには許可リストの項目のみを含めます。拡張機能のバージョン、配布チャネル、ブラウザー種別、表示言語、拡張機能内の入口、機能/操作 ID、結果、エラー分類、サイト種別、所要時間・件数・規模の区間値などです。公開された機能の保守、安全性、性能・信頼性の測定にのみ利用します。
  • 業務イベントに、アカウントの API キー、アクセス/更新トークン、Cookie、認証ヘッダー、アカウント名、プラットフォームのユーザー ID、メール、設定したサイト URL、メモ、インポート/エクスポート内容、生のエラースタック、API リクエスト/レスポンス本文は含めません。正確な残高、クォータ、使用量も送信しません。
  • 統計 SDK は、イベント時刻、ブラウザー、OS、端末/画面、拡張機能ページなどの技術情報を付加する場合があります。統計サービスは IP アドレス、HTTP リクエストのメタデータ、IP から推定した大まかな地域を処理・保存する場合もあります。業務項目のフィルタリングは、こうしたネットワーク情報が処理されないことを意味しません。
  • 自動ページビューイベント、自動操作収集、セッション録画は無効です。他のウェブサイトでの完全な閲覧履歴を製品統計として記録することはありません。

アンインストール時のフィードバック

アンインストール時、ブラウザーが当方のフィードバックページを開く場合があります。URL にはバージョン、インストールからの日数、言語を含めます。統計が有効な場合のみインストール統計 ID を含め、ページを開いたイベントを送信して以前の利用と関連付けます。無効な場合、ID とページを開いたイベントは送信しません。ただし、ページの読み込み自体はホスティングサービスへのネットワークリクエストを伴います。

理由を選び送信すると、その理由、任意のコメント（最大 500 文字）、上記のバージョンなどの情報が同じ PostHog プロジェクトに送信され、開発者が閲覧できます。製品統計を無効にしていても、明示的なフィードバック送信ではこれらの情報を送ります。その場合、以前のインストール統計 ID とは関連付けません。パスワード、API キーなどの機密情報をコメントに記入しないでください。

保存と安全性

  • ローカルデータ： アカウント、認証情報、設定、履歴は、初期状態では現在のブラウザープロファイルの拡張機能用ローカルストレージやローカルデータベースに保存します。ブラウザーによる保存領域の分離は、全ローカルデータを拡張機能が追加暗号化することを意味しません。端末やプロファイルにアクセスできる人は読み取れる可能性があります。
  • ローカルエクスポート： JSON ファイル、コピーした設定、共有スナップショットはユーザーが管理します。認証情報を含む場合があるため、共有前に内容を確認し、安全に保管してください。
  • WebDAV（任意）： 選択した範囲のバックアップを、入力されたユーザー名/パスワードで認証して設定先サーバーに送信します。アカウント認証情報を含む場合があります。バックアップの暗号化は設定によります。HTTPS を使用してください。ユーザーが設定した HTTP 接続の暗号化は保証できません。
  • GitHub Secret Gist（任意）： 入力された GitHub Token で API を呼び出します。バックアップはアップロード前にユーザーのパスワードを用いてローカルで AES-256-GCM 暗号化します。GitHub は認証 Token と暗号化バックアップを受信します。Gist Token、Gist ID、暗号化パスワードは手動 JSON エクスポートに含めません。Secret Gist は一覧に公開されないという意味で、リンクを本人だけが開けることを意味しません。クラウド同期も参照してください。
  • 統計とフィードバック： 設定された PostHog プロジェクトに保存し、PostHog がサービスを提供し、開発者がアクセスできます。PostHog のプライバシーポリシーと該当するサービス条件も適用されます。

当方はアカウント認証情報を集中的に保存するアカウント管理サーバーを運営していません。端末、バックアップ、同期パスワード、第三者アカウントを保護してください。完全に安全な保存・通信手段はありません。

データの共有先

当方はユーザーデータを販売・貸与せず、パーソナライズ広告やサイトをまたぐ広告追跡に利用しません。本ポリシーに記載した機能・処理のため、次の相手にデータを送信します。

受信者送信する場面とデータ
追加・選択した API プラットフォーム、管理サイト、関連する認証/上流サービスアカウント要求、ログイン、更新、チェックイン、キー/モデル管理、管理サイトへのインポート、API 検証に必要な認証情報、操作パラメーター、検証内容を送り、結果を読み取ります
設定した WebDAV 運営者、Gist 選択時の GitHubバックアップや自動同期でサービス認証情報とバックアップを送ります。暗号化は上記のとおりです
選択したエクスポート先ツール・アプリエクスポート、コピー、アプリ連携の操作時に、選択した URL、キー、設定を送ります。Cherry Studio、CC Switch など、宛先は操作で決まります
有効にした通知サービスTelegram、DingTalk、Feishu、WeCom、ntfy、カスタム Webhook に認証/送信先情報、通知タイトルと本文を送ります。タスク結果やサイト/アカウント関連情報を含む場合があります。ブラウザー通知はローカルブラウザーが扱います
PostHog とプロジェクト開発者統計有効時の上記イベント、およびユーザーが送信したフィードバック
GitHub、LDOH（ldoh.105117.xyz）、開いた外部サイト更新、プロジェクトのお知らせ、公開サイト索引取得時の通常のネットワーク情報。LDOH の照合はローカルで行い、検索リンクをクリックするとサイトのホスト名を検索条件として宛先に渡します
ドキュメント・アンインストールページの GitHub Pages ホスティングと、ページ要求が経由する CDNページ配信とサービス運用のため、閲覧時の IP、要求 URL（クエリを含む）、ブラウザーのリクエストヘッダーなどを受信します

第三者サービスが国外でデータを処理する場合があります。その保存、安全性、削除は各社のポリシーと設定によります。サポート依頼や GitHub Issue では、開発者と該当プラットフォームがユーザーの提供した情報を受信します。公開 Issue は他人も閲覧できます。

保存期間・削除・選択肢

  • アカウントと設定： 編集・削除または拡張機能データの消去までローカルに保存します。残高・使用量履歴は各機能の保存期間設定に従い削除します。ローカルのアカウント削除は、サービス側の退会や発行済み API キーの失効にはなりません。
  • アンインストール： 通常はブラウザーが拡張機能のローカルデータを削除します。別途エクスポートしたファイル、クリップボード、他の端末、リモートバックアップ、第三者サービス内のデータは自動削除されません。
  • リモートコピー： 自動同期を無効にしても WebDAV/Gist の既存バックアップは削除されません。対応するサービスでバックアップと履歴を削除し、必要に応じて Token を失効させてください。他の同期端末による再アップロードにも注意してください。
  • 統計とフィードバック： 統計の無効化やアンインストールは送信済みイベントを削除しません。拡張機能にはリモートイベントの自動期限削除や一括削除機能はありません。送信済みイベントとフィードバックは、プロジェクト内で削除されるか、適用されるサービス保存期間設定により消去されるまで PostHog に保存されます。統計の無効化やアンインストールを理由に自動で期限切れにはなりません。特定可能な記録の照会・削除は下記窓口で依頼できます。関連付け可能な識別情報がない記録は、本人の記録と特定できない場合があります。
  • 権限とバックグラウンド処理： ブラウザーで任意権限を取り消し、拡張機能で自動更新・チェックイン・同期・通知を無効にするか、利用を停止してアンインストールできます。

当方がアクセスできる統計・フィードバックの照会、訂正、削除は、まず依頼の種類を保守担当者へ連絡してください。認証情報を公開しないでください。記録の特定に必要な情報を確認する場合があります。

Chrome Web Store ユーザーデータポリシー

All API Hub はブラウザー API から取得したユーザーデータの利用・転送について、Limited Use 要件を含む Chrome Web Store ユーザーデータポリシーを遵守します。公開した単一目的とユーザー向け機能の提供・改善にのみ使用し、パーソナライズ広告、データ仲介業者への販売、信用評価や融資には利用しません。明示的な同意、必要なセキュリティ調査、法的義務、集計・非識別化したデータによる内部運用など、ポリシーで認められる場合を除き、人による閲覧を許可しません。

更新と連絡先

変更時には本ページと最終更新日を更新します。追加説明や同意が必要な変更は、該当する要件に従い製品内で対応します。ポリシーの更新自体は必要な許可の代わりにはなりません。

プライバシーに関する質問やデータの依頼は、GitHub の保守担当者またはプロジェクト Issueへ連絡してください。Issue は公開されています。API キー、パスワード、完全なバックアップ、機密の個人情報を添付しないでください。非公開での対応が必要な場合、まず保守担当者に利用可能な連絡方法を確認してください。
