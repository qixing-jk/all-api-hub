モデル一覧と価格比較

モデル一覧は、現在のデータソースが提供するモデルカタログを読み取り、絞り込み、比較、検証するためのページです。アカウントと API 認証情報のモデル、価格、利用可否をまとめ、現在読み込まれて比較可能なデータと実際の用途に基づいて、モデルとデータソースを選ぶために役立ちます。

機能の概要

  • 🔍 3 種類のデータソース：すべてのアカウント、指定アカウント、API 認証情報（API Credential Profile）。
  • 💰 アカウント間の価格比較：異なるアカウントの同じモデルをまとめ、現在利用可能な価格を統一基準で比較します。
  • 🎯 用途に近い見積もり：通常のチャット、コード補完、コーディングエージェントなどの用途を選ぶか、入力、出力、キャッシュの割合を調整できます。
  • 🏷️ 検索、絞り込み、並べ替え：モデル名や説明を検索し、ベンダー、課金方式、能力、グループ、検証結果で絞り込み、価格や遅延などで並べ替えます。
  • ✅ モデル検証：単体検証と一括検証はいずれも 1 回のプローブで、モデルまたはエンドポイントが現在利用可能か、CLI と互換性があるかを確認します。
  • 📦 モデルに対応するキー：互換性のあるキーを選ぶか、対応している場合はそのモデルに制限した Token を作成します。

アクセス方法

  1. 拡張機能のポップアップで モデル一覧 アイコンをクリックします。
  2. フルページ表示では、左側の インターフェース カテゴリから モデル一覧 を開きます。
  3. アカウント管理または API 認証情報ライブラリで モデル一覧で開く をクリックすると、対応するデータソースを直接開けます。

主な操作

1. データソースを選択

ページ上部の データソースを選択 ドロップダウンで切り替えます。

  • すべてのアカウント：追加済みの全サイトアカウントを集約し、サイト間で比較します。
  • 指定アカウント：1 つのアカウントのモデルカタログを表示します。
  • API 認証情報：API 認証情報ライブラリに保存した Base URL + API Key でモデルカタログを読み取ります。サイトアカウントを作成する必要はありません。

「プロバイダーカタログ / パーソナライズドカタログ」は、一部のアカウント内部のデータ範囲を示すもので、上部の独立したデータソースではありません。

データソースごとに提供できる情報が異なります。

データソース価格 / 倍率 / グループ説明
すべてのアカウント各アカウントの能力による集約比較に使用
指定アカウントアダプターによる価格、倍率、グループを提供するソースもあれば、モデルカタログだけのソースもあります
API 認証情報通常は提供されない主にモデル検出と検証に使用

提供元の公開カタログは公開モデルと価格を示すもので、特定のキーやプランでの利用を保証しません。キーの選択や検証操作は、データソースが対応している場合に表示されます。

カタログ価格は一部の課金条件のみを示す場合があります。グループ、長いコンテキスト、画像などの規則は公式リンクで確認してください。表示価格に含まれる割引は重ねて適用せず、課金上の意味が不明なゼロ値は無料として扱いません。

2. 検索、絞り込み、並べ替え

  • 検索：モデル ID、表示名、説明に一致します。サイト名は検索しません。
  • ベンダータブ：解析されたベンダー別に表示します。「未分類」も含まれます。
  • 課金方式：すべて / Token（従量課金）/ 1 回ごと。
  • モデル能力：画像、音声、動画、PDF、推論、ツール呼び出し、構造化出力など。ソースが能力情報を提供する場合だけ表示されます。
  • グループフィルター：アカウントグループで絞り込みます。すべてのアカウント表示では、比較に参加するグループをアカウント別に選択できます。
  • テスト結果：成功 / 失敗 / 未テスト。
  • 並べ替え：既定、価格の昇順、価格の降順、テスト遅延の昇順。すべてのアカウント表示では「同じモデルの最安値を優先」も利用できます。
  • 価格比較条件：価格で並べ替える場合に用途を選ぶか、入力、出力、キャッシュ読み取り、キャッシュ書き込みの割合を調整します。
  • 表示内容：実際のチャージ金額、エンドポイント種別。

絞り込みと並べ替えの操作は、現在のデータソースが対応している場合だけ表示されます。すべてのデータソースに全操作があるとは限りません。

3. 価格を比較

ワンクリック価格比較 をクリックすると、現在のフィルターを解除し、すべてのアカウントへ切り替え、同じモデルの最安値を優先して並べ替えます。

  • 比較条件を設定：用途に近いシナリオを選ぶか、入力・出力・キャッシュの割合を調整します。段階料金や条件付き料金では、案内に沿って入力・出力の長さや画像サイズなどを設定してください。長さは料金区分の選択に使われ、1 回のリクエストの使用量を表すものではありません。
  • 比較可能な価格を確認：同じ課金単位で、現在の条件を満たし、必要な料金情報が揃ったものだけを比較します。条件が不足する場合は入力してください。料金情報が不足する場合は理由を表示し、無料として扱いません。
  • 価格詳細を確認：100 万 Token・枚・秒・回など、表示された課金単位を確認してください。異なる単位は個別に比較します。モデルを展開すると、料金の詳細やグループ別の価格を確認できます。

価格ラベルの意味：

  • 通常の価格：サイトが明示した単価や課金規則をそのまま表示し、精度ラベルは付けません。グループ、段階、時間帯などの適用条件は別途説明します。
  • 換算済み：現在の為替レートで表示通貨を変換しています。元の通貨の価格は変わりません。
  • 見積価格：参考レート、グループ倍率、ポイント換算などの前提から推算した価格です。実際の請求はサービス提供者の情報を基準にしてください。
  • 最安値：現在のフィルターと比較条件で比較可能な価格のうち、最も低いものです。
  • 最適グループ：比較可能なグループのうち、1 つだけが最安値の場合に表示されます。最安値が同額の場合は、1 つを指定しません。
  • 価格比較はローカル計算で、現在読み込まれ、有効で比較可能な価格だけを対象にします。公式な保証、リアルタイムの全量データ、「インターネット上の最安値」を示すものではありません。
  • 欠落または不正な価格は比較不可で、0 や既定価格として扱いません。サイトが明示的に 0 を返す場合、そのモデルは実際に無料の可能性があります。
  • サイトの価格 API、公式カタログ、見積もりなど、価格ソースは異なる場合があります。ページでは可能な限りソースと精度を表示します。

ネイティブ利用枠の課金：Token やポイントなどの非通貨資産を表示・見積もり、同じ資産と宣言されたソース範囲内で並べ替えられます。同名の単位や異なるサイトの残高が等価とはみなしません。追加倍率が不明な参考消費量は、同一ソース内の基本消費量の並べ替えにのみ使用し、最終請求額やサイト間の最安値を表しません。

EMRank の利用枠は Token 単位で、1 M Token = 1,000,000 Token です。通貨価格と同じ入力・出力の表示で、モデルの百万 Token あたりの単価を示します。出力は無料です。通常は公開単価を表示し、価格順では既存の使用量の重みを使った参考消費量も表示します。ユーザーレベルや RPM などの追加倍率は課金ルールのヒントで確認できます。不明な倍率を 1 と仮定せず、参考値は最終請求額を表しません。米ドルや人民元への換算も行いません。EMRank の課金と利用枠も参照してください。

モデル行には用途、サイトでの利用可否、公開されたコンテキスト上限を表示します。詳細にはカタログの所有者、対応・既定のベクトル次元数、画像対応、公開日を、提供されている場合に表示します。不明な仕様は推測しません。呼び出し例のリンクは公式モデルページを開きます。埋め込み・再ランキング・意思決定モデルでは、対応しないテキスト生成や CLI の検証操作を表示しません。

4. グループ切り替えと最適グループ

データソースが複数のユーザーグループに対応している場合、グループフィルターで比較に参加するグループを限定し、モデルを展開してグループ別価格を確認できます。グループは実際の単価に直接影響します。価格を利用する前に、そのアカウントが該当グループを利用できることを確認してください。

「最適グループ」は現在のフィルターと比較条件に基づくローカル計算結果であり、サービス提供者の公式推奨や長期保証ではありません。

5. 1 モデルを検証

モデルカードの検証アイコンをクリックします。

  • API を検証：1 回のプローブを送信し、そのモデルまたはエンドポイントが現在利用可能で、応答が期待どおりかを確認します。
  • CLI 互換性を検証：ストリーミングやテキスト生成への対応など、CLI ツールに適しているかを評価します。

API を検証 ダイアログの テスト方式 で、ストリーミング（既定）または 非ストリーミング を選択します。生成系テストは選択した方式で実行され、結果と新しく保存される履歴に使用した方式が表示されます。エンドポイントがリクエストを拒否した場合は、方式を切り替えて再テストできます。テスト中に方式が自動で切り替わることはありません。モデル一覧の取得には影響しません。

CLI 互換性を検証 ダイアログでも、ストリーミング（既定）または 非ストリーミング を選択できます。各 CLI に対応する API 種別でツール呼び出しを確認し、結果にテスト方式を表示します。失敗時に方式が自動で切り替わることはありません。

  • 検証は1 回のプローブです。長期的な利用可能性や永続的な失敗を意味しません。
  • CLI 互換性検証は実際の外部 CLI を起動しません。プロトコルレベルのシミュレーションだけを行います。

6. 詳細な検証：描画テストとプロンプト

通常の検証履歴には状態、概要、所要時間のみを保存し、再表示時に元の入出力は復元しません。保存済みアカウント・認証情報の描画テストは、モデルごとに実行概要（成果物の状態、日時、所要時間、呼び出し回数）を保存し、既存の履歴削除規則に従います。SVG、Agent ファイル、ツールの詳細はセッション内のみ保持し、再表示時は概要のみ復元したことを明示します。未保存の認証情報によるウェブテストは永続化しません。

検証パラメーターは本文のコンパクトなグリッドに配置します。テスト結果の説明と既存の検証概要はダイアログのヘッダーに表示し、独立した色付きの通知枠は使用しません。各テストのプロンプト編集と 実行結果 は別々に表示され、実行後は結果が自動で開きます。テキスト応答は直接表示し、入力パラメーターと元の出力は必要に応じて展開できます。エディターには現在のプロンプトが表示され、結果に切り替えても未保存の変更は失われません。結果は現在の API、モデル、リクエスト設定に対するもので、完全な互換性を保証しません。

API を検証、CLI 互換性を検証、ウェブ API チェックの各ダイアログには、描画テストカードが常に表示されます。詳細セクションを開く必要はありません。実際のモデル呼び出しが発生するため、実行ボタンを押したときだけ実行し、検証を開始 や一括テストでは実行しません。

描画テスト は、自転車に乗ったペリカンの SVG を描かせて、絵柄と構造を直接見比べるためのものです。判定は目視で行います。ダイアログは SVG の抽出と図形の集計のみを行い、スクリプトや外部参照を含む回答は描画しません。

単一回答と Agent モードは、既定のユーザープロンプト Generate an SVG of a pelican riding a bicycle とカスタムプロンプトを共有します。Agent モードでは、ワークスペースの機能とタスクのファイル納品条件を別のシステム指示で伝え、ユーザープロンプトに描画要件を追加しません。

既定では単一の回答を使用します。Agent テストモード を有効にすると、モデルは仮想ファイルを一覧表示・読み書き・編集し、JavaScript（トップレベル await と Promise 対応）で作品を確認・修正できます。ターン数とツール操作回数に固定上限はなく、モデルが終了するか手動で停止するまで実行します。トークン使用量が増える場合があります。成果物は pelican.svg から読み込み、ターン数、ツール履歴、ファイルと所要時間を表示します。成果物がない場合も最終回答への自動切り替えは行いません。

ファイルは同じ実行内でのみ共有し、実ファイル、ブラウザー、ネットワークや Node API にはアクセスしません。仮想絶対パス、相対パス、Unicode ファイル名を使用でき、ファイル数とコード長の固定上限はありません。JS の既定予算は 5 秒、128 MiB で、timeout_ms（最大 60 秒）、memory_mb（最大 1024 MiB）で調整できます。ブラウザーのメモリー保護用にワークスペースは 64 MiB、ログと戻り値はそれぞれ 64 Ki 文字を予算とし、長い出力は切り詰めて明示します。出力が長くてもタスクやファイルを破棄しません。JS のグローバル環境は実行ごとに新しくなり、成功時のみファイル変更を反映します。ターミナル、npm、完全な CLI 環境は提供せず、描画品質は目視で判断します。

各テストカード内の プロンプトを編集 では、その検証が送信するプロンプト（テキスト生成、構造化出力、ツール呼び出し、ウェブ検索、埋め込み、画像生成、動画タスク）を個別に編集できます。エディターを開くと既定値が表示され、項目ごとに既定に戻せます。

  • 編集を止めると自動保存され、すべての検証入口（アカウント検証、API 認証情報の検証、ウェブ API チェック、一括テスト）に適用されます。描画テストは編集中のプロンプトを、その他のテストは保存済みのプロンプトを使用します。保存に失敗した場合は編集内容を保持し、エラーを表示します。
  • 空欄は組み込みの既定値を使う意味です。リセットは空文字ではなくキーを削除するため、将来の既定値変更も反映されます。

プロンプトは設定に保存され、テレメトリには含まれません。設定のエクスポートや同期には含まれる場合があります。

7. 一括テスト

ツールバーの 一括テスト をクリックして モデルを一括テスト を開きます。

テスト方式 の既定は ストリーミング で、非ストリーミング も選択できます。その回で選択した生成系テストはすべて同じ方式で実行され、各結果に使用した方式が表示されます。

  1. **テスト項目**を選びます。エンドポイント種別から自動判定するか、テキスト生成、ツール呼び出し、構造化出力などを明示的に選択できます。
  2. **実行するモデル**で、テストするモデルを選択または全選択します。
  3. **一括テストを開始**をクリックします。テストは最大 5 件の同時実行でキュー処理されます。いつでも **テストを停止**でき、それまでに得られた部分結果は保持されます。
  4. ダイアログには合計、成功、失敗、スキップの件数が表示されます。

適用できないテスト項目は自動的にスキップされます。結果はその時点のプローブ結果であり、参考情報です。

8. モデルに対応するキー

モデルカードのキーボタンをクリックして モデルに対応するキー を開きます。

  • 現在のモデルと互換性のあるキーを選択します。グループまたは能力が一致するキーだけが表示されます。
  • 対応している場合、**クイック作成でそのモデルに制限した新しい Token を作成するか、カスタム作成**を使用できます。

この操作で変更するのはキー / Token です。モデルカタログ自体は編集しません。

9. データを更新

**データを更新**をクリックすると、現在のデータソースへ再度リクエストし、関連するローカルキャッシュを無効にします。更新動作はデータソースごとに異なり、更新後のデータはソースの応答を基準にします。

よくある質問

質問回答
モデル価格が 0、または比較に参加できないのはなぜですか？サイトが明示的に 0 を返す場合、そのモデルは実際に無料の可能性があります。価格データが不完全な場合は比較不可として表示され、無料として扱いません。
サイト間の価格比較はどのように計算されますか？現在読み込まれ、有効で比較可能な価格をローカルで計算します。ページに表示されるソースと精度を確認し、実際の料金は各サイトの公開価格を基準にしてください。
「現在の条件では比較対象外」と表示されるのはなぜですか？キャッシュ読み取り価格など、現在の条件で必要な価格が不足しています。別の用途を選ぶ、割合を調整する、または価格を展開して利用可能な情報を確認してください。
検証結果が失敗または不明になるのはなぜですか？検証は 1 回のプローブで、権限、モデル制限、レート制限などの影響を受けます。最終的には対象ツールでの実際の動作を基準にしてください。
アカウントに価格や倍率がないのはなぜですか？データソースが価格、倍率、グループ情報を提供しない場合があります。たとえば API 認証情報は、通常モデル検出と検証だけに対応します。
