All API Hub - あなたの万能 AI 資産マネージャー

AI 中継サイトのアカウントと API 認証情報をまとめて管理するオープンソースのブラウザー拡張機能。CLIProxyAPI、New API、Sub2API などのセルフホスト型ゲートウェイの管理、残高確認、モデル価格比較、API 検証、暗号化 WebDAV バックアップに対応しています。

利用開始Chrome ウェブストアEdge アドオンFireFox アドオンSafari インストール

📊 複数サイトの資産ダッシュボード

複数の AI 中継サイトの残高、利用量、傾向、アカウント状態を一画面で確認し、分散した管理を一つにまとめられます。

🔑 API 認証情報ライブラリ

サイトアカウントを登録せず、共有されたものや日頃個別に収集した Base URL と API Key をまとめて保存し、情報の確認、テスト、エクスポートにすぐ使えます。

💰 サイト間モデル価格比較

各サイトのモデル価格を実質価格に換算し、よりお得なモデルやグループをひと目で見つけられます。

✅ 複数サイトの自動チェックイン

対応アカウントの毎日のチェックインをワンクリックまたはスケジュールで実行し、毎日のログインなしで特典を自動的に受け取れます。

🧪 API・モデル・CLI 検証

API の接続状態、モデルの利用可否、CLI の接続状態をワンクリックでテストし、設定上の問題をすばやく切り分けられます。

🔔 お知らせとタスク結果通知

登録済みサイトのお知らせを一か所で確認し、メンテナンス、モデル、価格などの更新に加えて、自動チェックイン、WebDAV 自動同期、モデル同期のバックグラウンドスケジュール結果もすぐに受け取れます。

🚀 Web ページからの取り込みとワンクリックエクスポート

Web ページから Base URL や API Key をすばやく検出し、よく使う AI クライアントへワンクリックでエクスポートできます。

🛠️ 主要 AI ゲートウェイ対応

CLIProxyAPI、New API、Sub2API、AxonHub、Claude Code Hub、Octopus、Veloera、DoneHub を一元管理し、保存済みのアカウントや API 認証情報からサイト設定をすばやく追加できます。対応サイトではモデル同期やリダイレクトも利用できます。

🔐 ローカル優先と自動同期

データはデフォルトでブラウザ内に保存されます。暗号化 WebDAV 自動同期を有効にすると、複数デバイス間で安全に同期し、パソコンを替えてもそのまま使い続けられます。

紹介

AI の時代には、節約したり別のモデルを試したりするために、複数の中継サイトアカウントを持つことがよくあります。ただし、管理は面倒になりがちです。残高は分散し、価格は比較しづらく、毎日の手動チェックインも忘れやすくなります。

All API Hub は、その問題を解決するためのツールです。 AI 資産を一元管理し、より簡単で見やすく、自動化された管理を実現します。

🎯 使用シーン

👤 一般の AI ユーザー（初心者向け）

  • どう始めればよいですか？：拡張機能をダウンロードしてインストール -> 最初のアカウントを追加
  • 節約したい：自動チェックインでクレジットを獲得 -> サイト間でモデル価格を比較
  • もっと手間を減らしたい：資産の変化をひと目で確認 -> アカウントを他の AI ツールに同期 -> バックグラウンドタスク通知を受信

🛠️ 上級ユーザー（Key コレクター）

  • キー管理：独立した URL+Key を API 認証情報庫に保存
  • 可用性テスト：API と CLI の互換性を一括検証
  • デバイス間同期：暗号化 WebDAV バックアップを設定

👑 サイト管理者（運営者向け）

  • 効率化ツール：拡張機能内でチャネルを管理 -> モデルを一括同期
  • 設定の最適化：モデルリダイレクトを設定
  • セキュリティ対策：2FA / OTP 検証を処理

🧩 サポートされているシステムアーキテクチャ

どのアーキテクチャを使っていても、高い確率で対応しています：

  • アカウントサイト互換アーキテクチャ：New API, One API, Sub2API, One-Hub, Veloera, Done-Hub など。
  • 特色あるアカウントプラットフォームと互換実装：OpenRouter、AnyRouter、AgentRouter、AIHubMix、Super-API、v-api、Neo-API など。
  • セルフホスト型管理バックエンド：CLIProxyAPI、New API、Sub2API、AxonHub、Claude Code Hub、Octopus、Veloera、DoneHub など。バックエンド管理に利用でき、対応サイトでは移行とモデル同期も行えます。

macOS で Safari を使う場合は、先に Safari インストールガイド を確認してください。 QQ / 360 / Brave / Vivaldi / Opera などのブラウザを使う場合は、その他のブラウザへのインストールガイド を確認してください。 ストア版が GitHub Releases より遅れる理由や、更新を手動で確認する方法を知りたい場合は、インストール方法と更新について を確認してください。
