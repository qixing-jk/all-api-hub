インストール方法と更新について

All API Hub には、よく使われるインストール方法が 3 つあります。ブラウザストア版、GitHub 自己更新版（Chromium .crx）、GitHub 解凍読み込み版 です。どちらを選べばよいか迷う場合は、まずブラウザストア版を使ってください。

かんたんな結論

Chrome、Edge、Firefox ユーザーは、対応するストア版を優先してインストールしてください。ストア版はインストールが最も簡単で、ポリシー設定も不要です。

ストア版が使えず（まだ公開されていない、ストア版や Chrome ウェブストア互換版をインストールできない）、GitHub の添付ファイルを使う必要がある場合だけ、Chromium 系ブラウザーでは添付形式を区別します。

  • 推奨：自己更新 .crx：ストア版と同じようにリリースのマニフェストから自動更新されるため、一度インストールすればパッケージを差し替える必要はありません。stock Chrome / Edge は拡張機能の許可リストポリシーを一度設定する必要があります（Linux は不要）。
  • .zip 解凍読み込み版：自動更新されないため、更新のたびに再ダウンロードと再読み込みが必要です。.crx をインストールできない場合にだけ使います。

どのバージョンをインストールすべきですか？

自分のブラウザは Chromium 系ですか？

通常は Chromium と考えてください。Firefox と Safari を除き、一般的な拡張機能対応デスクトップブラウザーは基本的に Chromium 系です。不明な場合は ブラウザー一覧 を確認してください。

GitHub には新しいバージョンがあるのに、ストアがまだ更新されていないのはなぜですか？

これは正常な動作です。プロジェクトでは通常、先に GitHub へ新しいバージョンを公開し、その後で各ブラウザストアへ提出します。ストア側では審査と配信が必要なため、少し遅れることがあります。

よくある理由は次のとおりです。

  • ストアが新しいバージョンをまだ審査中。
  • ストアの審査は通過したが、まだあなたのブラウザへ配信されていない。
  • ブラウザがまだ拡張機能の更新を確認していない。
  • 会社の端末、ブラウザポリシー、またはネットワーク環境が拡張機能の更新を制限している。

ストア版を使っている場合、通常はブラウザの自動更新を待てば十分です。急いで修正を使いたい場合は、下の手動チェック方法を試してください。

拡張機能内で更新を確認する

All API Hub の設定ページを開き、バージョン欄の 「更新を確認」 をクリックします。初回確認前は現在のバージョンを表示します。変更内容を読む場合は 「変更履歴」 から直接確認できます。

現在の配布パッケージに応じて確認先が変わります。Firefox Add-ons 版は AMO の公開版、GitHub Release 版は最新の正式版を確認します。Nightly はソースのコミットを比較するため、バージョン番号が同じでも新しいビルドを検出します。Chrome と Edge のストア版は、ブラウザーに更新の準備ができているかも確認します。旧版や未指定のパッケージでも手動確認は可能です。自動確認への対応はインストール環境によって異なります。

表示される結果には、次のようなものがあります。

  • 最新バージョンです：対応は不要です。変更履歴で更新内容を確認できます。
  • 更新があります：「更新をダウンロード」 から対応するリリースページまたは Firefox Add-ons を開きます。AMO での公開は Firefox のダウンロード完了を意味しません。
  • ストアでの更新を待っています：ストア版はブラウザーが自動更新します。ストアでの配信をお待ちください。
  • 更新の準備ができました：ブラウザーが更新を準備できています。再読み込みして適用します。
  • 更新を確認できませんでした：ネットワーク、GitHub / AMO へのアクセス、またはブラウザーの更新確認が一時的に利用できない可能性があります。もう一度確認してください。

注意

拡張機能内の確認でストア審査を省略することはできません。GitHub に新版が公開されても、ストアに掲載されるまではストア版をそのバージョンに直接更新できません。

ブラウザ側でストア更新を手動確認する

Chrome または Edge のストア版を使っている場合は、ブラウザに拡張機能の更新確認を実行させることもできます。

Chrome

  1. アドレスバーで chrome://extensions/ を開きます。
  2. 右上の デベロッパーモード をオンにします。
  3. ページ上の 更新 をクリックします。
  4. ブラウザが拡張機能の更新を確認するまで待ちます。

Edge

  1. アドレスバーで edge://extensions/ を開きます。
  2. 開発者モード をオンにします。
  3. ページ上の 更新 をクリックします。
  4. ブラウザが拡張機能の更新を確認するまで待ちます。

この方法で更新できるのは、ストアがすでに提供しているバージョンまでです。ストアがまだ審査中の場合、新しいバージョンは表示されません。

Firefox

Firefox は通常、拡張機能を自動更新します。about:addons を開いて拡張機能管理ページに入り、利用可能な更新があるか確認することもできます。Firefox のバージョンによって、ボタンの位置が少し異なる場合があります。

GitHub からインストールするのはどんなときですか？

GitHub の添付ファイルは、次のような場合に向いています。

  • ストア版に、急いで必要な修正がまだ届いていない。
  • 現在使っているブラウザに利用可能なストア版がなく、Chrome ウェブストアなどの互換ストア経路も使えない。
  • 新しいバージョンで問題が解決したか確認したい。

GitHub の添付ファイルには 2 種類あり、更新方法がまったく異なります。

  • 自己更新 .crx（GitHub 添付ファイルで推奨）：ブラウザーがリリースの updates.xml から自動的に新しいバージョンを取得するため、パッケージを手動で差し替える必要はありません。stock Chrome / Edge は拡張機能の許可リストポリシーを先に設定する必要があります（Linux は不要、Windows の Edge はドメイン参加も必要）。詳しくは Chromium 自己更新インストール を参照してください。
  • 解凍読み込み .zip：自動更新されません。更新のたびに再ダウンロードと再読み込みが必要なため、.crx をインストールできない場合にだけ使います。

インストール前に次の点に注意してください。

  • ストア版から GitHub 版へ切り替える前に、データをバックアップとしてエクスポートしておくことをおすすめします。.crx、.zip、ストア版は拡張機能 ID が異なるため、データは自動的に移行されません。
  • 明確にテスト目的でない限り、複数の提供元から All API Hub を長期間同時にインストールすることはおすすめしません。
  • Firefox には GitHub の自己更新経路がなく、*-firefox.zip も自動更新されません。Firefox Add-ons ストア版を使ってください。

インストールと更新の手順は、その他のブラウザへのインストールガイド を確認してください。

よくある質問

「更新を確認」を何度も押す必要がありますか？

いいえ。ストア版と自己更新 .crx はどちらもブラウザが自動更新します。GitHub に新しいバージョンが公開されたことを確認したい場合、ストア版がすでに更新可能か確かめたい場合、または .crx の更新をすぐに適用したい場合だけ、手動で確認してください。

拡張機能内の「更新を確認」は GitHub のインストールパッケージを自動でダウンロードしますか？

いいえ。現在の配布チャンネルのバージョン状態を確認し、Releases またはストアページを開けますが、GitHub パッケージを自動ダウンロードしません。解凍読み込み版は手動でダウンロードして更新します。

「再読み込みして更新」をクリックするとデータは消えますか？

消えません。すでにダウンロード済みのストア更新を反映するだけです。アカウント、Key、設定などのデータは、ブラウザの拡張機能ストレージに残ります。

GitHub には新しいバージョンがあるのに、拡張機能ではストア更新がないと表示されます。どうすればよいですか？

ストア版を使っている場合は、まずストアの審査と配信を待ってください。急いで修正が必要な場合は、一時的に GitHub Stable の自己更新 .crx をインストールできます。利用前にバックアップをエクスポートしておくことをおすすめします。

GitHub 版はどうやって更新しますか？

  • 自己更新 .crx：ブラウザーが自動更新します。chrome://extensions/ の「更新」で今すぐ確認することもできます。
  • 解凍読み込み .zip：新しいパッケージをダウンロードし、新しい拡張機能ディレクトリを読み込み直します。詳しい手順は、その他のブラウザへのインストールガイド を確認してください。
