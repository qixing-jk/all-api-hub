Safari 拡張機能のインストール

このガイドでは、Mac で All API Hub Safari 拡張機能をインストールし、継続して使う方法を説明します。Safari 拡張機能は付属の macOS アプリを通じてインストールします。セットアップ後、アカウントと設定はローカルに保存されます。

検証済み環境

このインストール手順は macOS 26.6.2、Safari 26.6.2 で実際に検証しました。これは実際にテストした環境であり、最低システム要件を示すものではありません。

インストール

  1. All API Hub の最新リリースを開き、all-api-hub-<バージョン>-safari-xcode-bundle.zip をダウンロードします。ファイル名が -safari.zip だけの添付ファイルは選ばないでください。
  2. アーカイブを展開し、中にある Xcode プロジェクトを見つけて Xcode で開きます。
  3. Xcode の上部で macOS アプリと実行先の Mac を選び、Product > Run をクリックします。署名について確認された場合は、画面の案内に従ってローカル実行用のオプションを選びます。
  4. Safari でまず Safari > 設定 > 詳細 を開き、「Web デベロッパ用の機能を表示」を有効にします。その後、Safari > 設定 > 開発者 で「署名されていない拡張機能を許可」を有効にします。Mac のログインパスワードを求められる場合があります。
  5. Safari > 設定 > 拡張機能 を開いて All API Hub を有効にし、必要に応じて Web サイトへのアクセスを許可します。
  6. Safari のツールバーにある拡張機能アイコンをクリックして使用します。

拡張機能が一覧に表示されない場合は、Xcode から付属の macOS アプリをもう一度実行し、Safari の拡張機能設定を開き直してください。

Safari を次回起動するとき

Safari を終了すると「署名されていない拡張機能を許可」の設定がリセットされます。Safari を再度開くたびに、この設定を有効にしてください。通常、All API Hub macOS アプリを再起動する必要はありません。初回インストール、再インストール、または Safari が拡張機能を見つけられない場合に起動してください。この操作は拡張機能を実行できるかどうかに影響しますが、拡張機能のデータは削除されません。

データの保存場所

アカウントや設定などの拡張機能データは、現在の Safari 拡張機能のローカルストレージに保存されます。通常、Safari を終了または再起動しても消えません。Safari、Chrome、Firefox、他のデバイス間でデータは自動同期されません。別のブラウザーやデバイスに移す場合は、データのインポートとエクスポートまたは WebDAV バックアップを使用してください。拡張機能をアンインストールしたり Safari の拡張機能データを消去したりする前に、バックアップをエクスポートしてください。

Safari での機能差

Safari では、他のブラウザーで利用できる拡張機能 API の一部が提供されていません。

  • サイドパネル API は利用できません。ツールバーポップアップまたはオプションページを使用してください。
  • Safari のブックマーク API からアカウントをインポートすることはできません。手動で追加するか、バックアップをインポートしてください。
  • 拡張機能の通知 API は利用できません。タスク結果は拡張機能内で確認してください。
  • 拡張機能の clipboardRead 権限は利用できません。内容を読み取る場合は、テキストを選択するか手動で貼り付けてください。
  • Safari の個別 Cookie リクエストは付属の macOS アプリが処理します。拡張機能に対象サイトへのアクセスを許可し、必要な Cookie 権限を付与してください。HTTPS に対応し、HTTP はローカルの 127.0.0.1 テストに限られます。権限がない場合やネイティブアプリが利用できない場合、Web サイトの現在のログイン状態に切り替えず、リクエストを停止します。ポップアップでアカウントを更新しても反映されない場合は、オプションページから更新してください。

サイトごとに利用できる機能が異なる場合があります。拡張機能をインストールしても、すべてのサイトで全機能が使えるとは限りません。

更新とアンインストール

更新： 最新リリースから Safari Xcode プロジェクトのアーカイブをダウンロードし、Xcode で新しいアプリを開いて実行します。その後、Safari の拡張機能設定で All API Hub が有効になっていることを確認します。同じ拡張機能のインストールを更新すればローカルデータは引き継がれますが、大切なデータは事前にバックアップしてください。

アンインストール： Safari > 設定 > 拡張機能 で All API Hub のチェックを外し、インストールした All API Hub macOS アプリを削除します。保存データも削除する場合は、Safari の Web サイトと拡張機能のデータ設定から該当データを削除してください。

よくある質問

なぜ Xcode プロジェクトを開く必要がありますか？

Safari は付属の macOS アプリに拡張機能を含めてインストールします。ダウンロードしたアーカイブにはプロジェクトと必要なファイルが含まれています。Xcode で一度実行した後、Safari の設定で拡張機能を有効にしてください。

Safari の再起動後に拡張機能が動かなくなりました。データは消えましたか？

通常、データは消えていません。Safari の終了時に「署名されていない拡張機能を許可」がリセットされるため、再度有効にしてください。Safari が拡張機能を見つけられない場合は、付属アプリを起動してください。アカウントと設定は Safari のローカル拡張機能ストレージに保存され、この設定のリセットでは削除されません。

新しいデバイスでアカウントを復元するには？

元のデバイスでデータをエクスポートするか、WebDAV バックアップを設定してください。新しいデバイスに拡張機能をインストールした後、データをインポートするかバックアップを復元します。ブラウザー間でデータは自動同期されません。
