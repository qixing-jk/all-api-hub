# 分包与初始占用优化：采纳范围和评估记录

Status: ready-for-human

2026-11-14。优化起点 `c9693309df`，收敛前版本 `4d4fc037f0`。用户决定：先保留收益明确的工作；已加入、原有及计划中的其他优化都须明确评估。本文取代此前将新增 UI lazy 视为默认采纳的建议，不修改历史实验记录。

## 采纳规则

每项分别记录来源、收益证据、首次使用代价、生命周期/兼容性成本和决定。测试通过证明行为，不能证明性能收益；候选模块排除构建只代表可移动代码上限。历史整轮指标不能分摊为单项收益，也不能当作当前分支指标。

小范围依赖隔离可以凭实际产物移除重依赖、明确职责边界及行为验证采纳。改变加载时机或缓存寿命时，需要额外衡量启动收益和首次使用代价。旧优化的保留不等于已证明其性能最优；证据不足时保留原有行为，单独测量后再改。

独立实验须固定源码/构建/浏览器/数据，只改变一项，交替采样冷启动与首次/再次动作，记录实际请求字节、耗时离散程度及适用的稳定/峰值堆。基于噪声决定是否增加样本，不能只报最好值。必须保持正确执行、取消、失败恢复、焦点、旧结果失效和跨上下文语义。收益不稳定、首次动作明显退化，或需要额外协议/权限/长期状态才能成立时，不采纳。

## 优化起点之前已有的机制

| 机制 | 已确认事实 / 未知 | 评估与复评条件 |
| --- | --- | --- |
| Options 页面、BasicSettings 次级标签、popup 非默认视图及统计 | 真实资源请求断言覆盖部分页面；用户进入相应页面才需要这些模块。各路由首用耗时未逐一对照。 | **保留原有行为**。低成本常规导航边界；仅在出现可测等待或重依赖回流时单独实验。BasicSettings 根页不在此类保留项中。 |
| KiloCode 两类导出、CherryStudio 集成 | 按明确用户操作触发；普通密钥列表无需导出工作区。缺少独立性能 A/B。 | **保留原有边界并修复体验**，不增加更多导出分包。冷加载失败/取消/重开测试随实际 Kilo 入口迁移。 |
| CheckInFeedback 对话框 | 按显式操作加载，已有等待取消、会话标识与旧结果失效；尚无独立首用 A/B。 | **保留原有实现**。出现可测等待再评估，不改用新增 DeferredDialog。 |
| 拖拽运行时 | 只在重排模式需要，已有加载/失败状态；大账户量重排成本未测。 | **保留**。先测重排首用与大列表，再考虑预热；不在启动时预热。 |
| QuickJS、tokenizer、词表 | tokenizer 生产页验证预览0词表读取、并发同编码复用、503后恢复、取消和已知计数；3次Chrome词表首用约33.9/63.8 ms、热用0.2 ms，两编码加载后页面堆增量约12.7 MiB，非RSS/峰值。QuickJS已有清理逻辑。 | **保留现有按需及有界缓存**。缺长任务峰值/worker重启/长期驻留数据，不加TTL或worker。 |
| 当前/回退语言 JSON、日期库 locale | 已按语言加载并缓存，失败可重试；内容启动仍读完整当前/回退资源。 | **保留**。进一步按命名空间拆分须验证错误消息、语言切换、首次提示和多页面成本，不凭资源大小决定。 |
| 虚拟账户列表 | 普通模式用Virtuoso，重排模式全量渲染；未跑100/500/1000账户性能曲线。 | **保留**，不是新增机会。先测搜索/排序/滚动/重排再改阈值或状态结构。 |
| 请求合并、批次库存 cache、后台初始化 Promise | 源码已有pending复用、失败清除或批次范围缓存；后台调度监听同步注册。未逐服务测启动CPU与读取次数。 | **保留**。新缓存必须证明减少实际重复工作并保持凭据隔离、取消与写后可见性。 |
| content UI 按需挂载及内容/后台内部 import() | 当前 WXT IIFE 内通常内联；延迟调用/挂载不等于独立资源下载。 | **保留原有组织方式**。不把 import 数量或入口小文件算分包收益。 |

## 已撤回的实验和其余候选

| 项目 | 预期收益 / 主要代价 | 决定与进入条件 |
| --- | --- | --- |
| 整个 content ESM | 每页少解析 UI；涉及即时复制事件、动态资源URL、上下文共享。先前部分修正后仍有4个首次触发场景失败。 | **已撤回，不继续实现**。任何后续内容能力实验必须保持第一次操作可靠。 |
| 自定义后台CJS/预缓存 | 小入口不代表总启动/内存下降；worker重启与Firefox等价生命周期未完整成立。 | **已撤回**。没有稳定后台收益证据，不恢复自定义加载器。 |
| 单个低频内容能力原生注入 | 可能减少未使用页面成本；增加消息、注入幂等、导航/权限/并发处理。成熟源码研究不等于本仓收益。 | **暂缓**。先确定可隔离字节与普通页面成本，再独立测首次复制、取消、重注入和后台休眠后首动作，不扩大权限。 |
| 存储读取/归一化与后台初始化 | 可能减少重复克隆/读取；跨上下文cache存在一致性风险。 | **仅测量优先**：记录调用次数、时序和耗时，先评估一次操作内复用。 |
| Markdown/图表继续细拆、其他素材/格式、依赖替换 | 可能减初始或总包；共享重叠、额外请求及兼容成本未测。 | **暂缓**。先以实际完整产物和调用路径确认独立可节省量；已有页面边界不重复细拆。 |
| TTL、offscreen/独立worker、tokenizer新格式 | 可能减少保留堆；增加重复初始化、复制数据和生命周期成本。 | **暂缓**。先测长任务峰值、结束后回落和重复使用；无具体问题不实施。 |
| 多标签、长期sidepanel、低端/最低支持浏览器 | 这是缺失的评估场景，而不是已证明的新优化。 | 先采样启动CPU、首次/热动作、峰值/稳定堆和后台重启。Firefox既有原生popup间歇尺寸问题未归因，不算本轮已修复。 |
