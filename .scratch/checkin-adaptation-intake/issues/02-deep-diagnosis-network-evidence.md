# 可选签到线索扫描（切片 B）

Status: resolved

Blocked by: 01

Parent spec: `../spec.md`，Part 2 为本票依据，具体预算与字段过滤规则只在 parent spec 维护。

## Objective

用户点击“收集更多线索”，自动获取可能的签到接口与前端路由信息，帮助维护者调查。可以跳过；没有结果也可以创建 issue。

## Scope

- 按钮旁简短说明状态查询会复用已有 AccessToken（Cookie 认证跳过并说明）、静态资源扫描会访问本站公开资源，无额外确认向导。
- 复用已确认只读的状态 GET；可加入有源码依据的固定兄弟状态路由。实现时记录来源，没有来源或没有只读能力则跳过。
- 在实际请求解析处采集 HTTP 状态和有限顶层键名，不改造归一化 detection 层去反推原始响应。
- 扫描同源 HTML 直接引用的公开 JS，提取签到相关 URL/路径字面量，仅输出去除查询、片段与 origin 的路径。不执行 JS，不递归扫完整 chunk 图，不请求新发现的路径。
- 不输出认证头、完整响应、原始 message 或整个 JS 内容；简单过滤按 parent spec 实施，不建设通用秘密检测器。
- 固定预算控制请求数、读取字节与运行时间；公开资源不带账号认证或 Cookie，拒绝重定向。
- 显示完成/部分完成/无结果；保留已有线索及用户编辑。关闭取消、忽略迟到结果，不后台重试。
- 结果只进入当前可编辑报告，不持久化，不改变签到选择或执行逻辑，不新增 telemetry 或持久化类型隔离体系。

## Validation / Acceptance

- 正常状态接口和 JS 路径能贡献线索，无结果也能申请。
- 验证只读调用、扫描发现的路径不被请求、同源资源和凭据隔离、输出字段过滤。
- 覆盖请求/字节/时间预算、部分失败、关闭取消，不丢失用户编辑。
- 报告不写入账号或备份，复制与预填使用当前最终预览。
- 运行相关测试与多语言检查；无需证明任意输入绝对不存在秘密。
