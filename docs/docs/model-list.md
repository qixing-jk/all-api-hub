# 模型列表与价格比对

> 模型列表用于读取、筛选、比较和验证当前数据源提供的模型目录。它不是通用的远端模型管理后台：页面展示的是各数据源返回的模型、价格和验证信息，并按“当前已加载且可比较的数据”做比较。

## 功能概览

- 🔍 **三类数据源**：所有账号、指定账号、API 凭据（API Credential Profile）。
- 💰 **价格与倍率比较**：在来源提供价格、倍率和分组数据时，本地计算并比较各模型的价格；价格比较只覆盖当前已加载、价格有效且口径可比较的数据。
- 🏷️ **搜索、筛选与排序**：按模型名称/描述搜索，按厂商、计费方式、能力、分组、验证结果筛选，并按价格、延迟等排序。
- ✅ **模型验证**：单个与批量验证都是一次探测（probe），用于判断模型/接口当前是否可用、是否兼容 CLI。
- 📦 **模型对应密钥**：为模型选择兼容的密钥，或在能力允许时创建限制到该模型的 Token。

## 进入方式

1. 在扩展弹窗点击 **`模型列表`** 图标。
2. 打开完整标签页，在左侧 **接口** 分类下进入 **`模型列表`**。
3. 在账号管理或 API 凭据库中，也可通过 **`在模型列表中打开`** 直接进入。

## 核心操作指南

### 1. 选择数据源

在页面顶部的 **`选择数据源`** 下拉框中切换数据源：

- **所有账号**：聚合已添加的全部站点账号，用于跨站比较。
- **指定账号**：查看某个账号的模型目录。
- **API 凭据**：使用 API 凭据库中保存的 `Base URL + API Key` 读取模型目录（无需创建站点账号）。

> “提供商目录 / 个性化目录”是某些账号内部的数据范围说明，不是顶部独立的数据源选项。

不同数据源能提供的信息不同：

| 数据源 | 价格/倍率/分组 | 说明 |
|------|------|------|
| 所有账号 | 视各账号能力 | 用于聚合比较 |
| 指定账号 | 视适配器而定 | 部分来源提供价格、倍率、分组；部分只有模型目录 |
| API 凭据 | 一般不提供 | 主要用于模型发现与验证 |

### 2. 搜索、筛选与排序

- **搜索**：匹配模型 ID、显示名称和描述；不按站点名称搜索。
- **厂商标签**：按解析出的厂商分类查看（含“未分类”）。
- **计费方式**：全部 / Token（按量）/ 按次。
- **模型能力**：图片、音频、视频、PDF、推理、工具调用、结构化输出等（仅在来源提供能力说明时出现）。
- **分组筛选**：按账号分组过滤；所有账号视图下可按账号分别选择参与比较的分组。
- **测试结果**：成功 / 失败 / 未测试。
- **排序方式**：默认顺序、价格从低到高、价格从高到低、测试延迟从低到高；所有账号视图下还有“同模型最低价优先”。
- **显示内容**：真实充值金额、显示倍率、端点类型。

> 筛选和排序控件只在当前来源支持时出现；不要假设每个来源都有全部控件。

### 3. 价格与倍率

模型卡片会展示来源提供的计费信息：

- **计费倍率 / 补全倍率**：来源返回的模型倍率（如 `1.5`）和补全倍率（如 `2`）。
- **分组倍率**：当前分组对应的额外倍率。
- **单价**：按每 1M tokens（输入/输出/缓存）或每次调用展示。
- **最低价 / 最优分组**：在“所有账号”或分组筛选范围内，本地计算出的较低价格选项。

> - 价格比较是**本地计算**，只覆盖当前已加载、价格有效且口径可比较的数据；它不是官方承诺、实时全量数据或“全网最低价”。
> - 缺失或非法的价格**不可比较**，不会按 `0` 或默认价格处理；`0` 也不一定代表免费。
> - 价格来源可能不同（如站点定价接口、官方目录、估算值），页面会尽量标明来源与精度。

点击 **`一键比价`** 会清空当前筛选、切换到所有账号，并按同模型最低价优先排序，适合快速开始跨站比较。

### 4. 分组切换与最优分组

如果一个来源支持多个用户分组，可以在分组筛选中切换，查看不同分组下的价格变化；价格排序会在已选分组范围内自动取最优价。**“最优分组”是本地计算结果**，不是服务商官方推荐或长期保证。

### 5. 单模型验证

点击模型卡片的验证图标：

- **验证接口**：发送一次探测请求，确认该模型/接口当前是否可用、返回是否符合预期。
- **验证 CLI 兼容性**：评估该模型是否适合 CLI 工具（如是否支持流式输出、文本生成等）。

> - 验证是**一次探测**，不代表长期真实可用，也不代表永久失效。
> - CLI 兼容性验证**不会启动真实外部 CLI**，只做协议级模拟检查。

### 6. 批量测试

点击工具栏的 **`批量测试`** 打开 **`批量测试模型`** 弹窗：

1. 选择 **`测试项目`**（可按接口类型自动识别，或选择文本生成、工具调用、结构化输出等）。
2. 在 **`执行模型`** 中勾选/全选要测试的模型。
3. 点击 **`开始批量测试`**；测试会排队运行（最多并发 5 个），可以随时 **`停止测试`**，并保留已产生的部分结果。
4. 弹窗会显示总计、通过、失败、跳过的数量。

> 不适用的测试项目会自动跳过；结果是当时的探测结果，仅供参考。

### 7. 模型对应密钥

点击模型卡片的密钥按钮，打开 **`模型对应密钥`**：

- 为当前模型选择兼容的密钥（仅列出分组/能力匹配的密钥）。
- 在能力允许时，可以为模型 **`快速创建`** 一个带模型限制的新 Token，或使用 **`自定义创建`**。

> 该操作修改的是“密钥/Token”，不会编辑模型目录本身。

### 8. 刷新数据

点击 **`刷新数据`** 会重新请求当前数据源，并使相关本地缓存失效。不同来源的刷新行为略有不同；刷新后的数据以来源返回为准。

## 列表控制项

| 配置项 | 说明 |
|------|------|
| **数据源** | 所有账号 / 指定账号 / API 凭据 |
| **搜索框** | 按模型 ID、显示名称、描述模糊搜索 |
| **厂商标签** | 按厂商分类查看 |
| **计费模式** | 全部 / Token（按量）/ 按次 |
| **模型能力** | 图片、音频、视频、PDF、推理、工具调用等（来源提供时出现） |
| **分组筛选** | 按账号分组过滤 |
| **测试结果** | 成功 / 失败 / 未测试 |
| **排序方式** | 默认、价格升/降序、测试延迟、同模型最低价优先 |
| **显示内容** | 真实充值金额、倍率、端点类型 |

## 功能边界

- 模型列表**不提供**对远端模型的新增、编辑、删除、启用/禁用或批量同步。
- 自建站点的模型同步属于独立功能，请参阅 [Managed Site 模型同步](./managed-site-model-sync.md)。

## 常见问题

| 问题 | 说明 |
|------|------|
| 为什么有的模型显示价格为 0？ | `0` 可能是有效免费价格，也可能来自站点未提供有效计费数据的占位；缺失或非法价格不可比较，不会回退为默认价格。 |
| 跨站比价是怎么计算的？ | 价格比较基于当前已加载、价格有效且口径可比较的数据做本地计算；来源和精度以页面标注为准，实际费用以各站点公布价格为准。 |
| “最优分组”是什么意思？ | 在已选分组范围内自动选择倍率最低的分组，是本地计算结果，不是官方推荐或长期保证。 |
| 为什么验证结果显示失败/未知？ | 验证是一次探测；可能受权限、模型限制、频率限制等影响，请以工具实际调用情况为准。 |
| 为什么我的账号没有价格/倍率？ | 该来源可能不提供价格、倍率或分组数据（例如 API 凭据只提供模型发现与验证）。 |
