# 自动识别排查指南

本页用于排查在插件「新增/编辑账号」中点击 **自动识别** 时出现的：识别耗时过长、无限等待、识别失败（401/403/格式错误等），以及无法提交等问题。

## 识别耗时过长（一直在“识别中...”）

自动识别需要打开临时页面并读取站点信息，遇到以下情况会明显变慢：

- **站点启用了 Cloudflare / 防火墙验证**：请留意是否弹出了临时窗口；如果需要人工点选验证，请在超时前完成验证。
- **网络/站点响应慢**：建议稍等片刻，或切换网络/代理后重试。
- **权限不足**：确认扩展可访问目标站点，并按所选认证方式授予必要权限。可选权限的用途与说明见 [权限管理](./permissions.md)。

## 识别失败：先确认真的已登录

自动识别依赖你在同一浏览器中已经登录目标站点：

1. 先在浏览器打开目标站点后台（控制台）页面。
2. 确认没有被重定向回登录页（刷新页面验证一次）。
3. 再回到插件执行自动识别。

## Requesty：创建管理密钥并识别

输入 `https://app.requesty.ai` 后，点击 **创建 Requesty 管理密钥并识别**。插件会使用当前浏览器中的 Requesty 登录会话创建管理密钥，验证后填入账号信息；表单已有密钥时，重新识别会复用该密钥。

已经保存过该站点账号且其中的管理密钥仍有效时，新增不会重复创建，而是复用已保存的密钥并提示说明。自动创建的密钥名为 `All API Hub - Account Connection (xxxxxxxx)`，可在 API Keys 页面识别；Requesty 不支持改名，不再需要时请直接删除。

管理密钥是账号凭据，不是交给客户端的密钥。密钥管理中它标记为当前账号凭据：可以查看和复制，但不会导出、批量导出，也不会被选为默认密钥——因为它能创建和删除组织内所有其他密钥。推理请使用单独的普通密钥；账号还没有这类密钥时，自动配置会新建一把。

未登录时，请先登录 Requesty 再重试。自动创建不可用时，可在 API Keys 页面手动创建启用 **Admin Permissions** 的密钥并粘贴到表单。若提示创建结果无法确认，请先查看 API Keys 页面，避免重复创建；已取得但验证失败的密钥会保留在表单中供重试。

## 识别失败：尝试切换认证方式

不同站点/魔改版本对接口与登录态处理不同，识别失败时优先尝试切换认证方式：

- **访问令牌认证失败**：切换到 **Cookie 认证** 后再次自动识别。
- **AnyRouter**：必须使用 **Cookie 认证**，并且 Cookie 必须来自当前已登录的账号；Cookie 认证不支持同站点多账号同时使用。


## 识别出的站点类型不对

自动识别按固定顺序取信号：先看域名，再看部署对外声明的站点名称（`/api/status` 返回的 `system_name`），最后才看页面标题。因此“页面外壳标题是 New API、背后实际跑的是某个魔改版本”的部署，也能按它自己声明的品牌识别出类型。

如果识别结果仍与实际不符：

1. 在「编辑账号」里手动把 **站点类型** 改成正确的类型并保存。站点类型决定扩展调用哪一套接口，比品牌名称更重要。
2. 不确定该改成哪个时，先跑一次签到（例如账号的「快速签到」），或在编辑账号里点一次「重新检测签到方式」：扩展会依站点自身的信号推断它对应的类型，并把推断结果写进编辑弹窗的提示、“自动签到 → 执行结果”、密钥管理的失败提示，以及「总览 → 需要处理」列表。
3. 改好类型后重新识别一次，确认能找到可用的签到方式。

这条提示只在账号仍保持“记录时的站点类型”时出现；一旦你改过站点类型，旧记录立即失效，不会再用过期的类型名误导你。扩展后来读到站点与保存的类型一致时，旧记录同样失效。

## 无法提交 / 无法保存：逐项检查必填项

当必填项未满足时，提交按钮会被禁用或保存失败。不同站点需要的字段不同，请先确认站点类型，再按对应要求检查：

- **New API 及兼容站点**：检查站点名称、用户名、用户 ID、访问令牌，以及大于 0 的充值金额比例；改用 Cookie 认证时，需要导入或填写会话 Cookie（Header 值）。
- **Sub2API**：检查站点名称、用户 ID、JWT 访问令牌和充值金额比例；不支持 Cookie 认证。开启“插件托管会话（多账号）”时，还必须导入或填写 Refresh Token。
- **OpenRouter**：检查站点名称、OpenRouter Management Key 和充值金额比例；无需填写用户 ID，也不支持 Cookie 认证。
- **其他站点**：以表单当前显示的必填标记为准，并参考 [手动添加账号指南](./add-account.md#manual-addition) 中对应站点的说明。

## 最后的手段：手动添加账号
如果自动识别始终无法完成，可切换到 **手动添加**，补齐信息，再保存账号。

详见 [手动添加账号指南](./add-account.md#manual-addition)。
