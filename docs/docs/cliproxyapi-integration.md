# CLIProxyAPI 管理

CLIProxyAPI 已接入 All API Hub 的管理站点功能。配置一次连接后，即可在插件中查看、创建、编辑和删除上游提供商，也可以从账号密钥或 API 凭据库导入。

## 配置连接

1. 打开 **设置 → 管理站点**，将站点类型切换为 **CLIProxyAPI**。
2. 填写部署地址，例如 `http://localhost:8317`。也可以填写原有的 `http://localhost:8317/v0/management`；通过反向代理部署时，请保留地址中的路径前缀。
3. 填写 CLIProxyAPI 的 **管理密钥**。它用于管理接口鉴权，与提供给客户端调用模型的 API Key 不同。
4. 保存后检查连接，再进入 **渠道管理**。

如果以前已经配置过独立的 CLIProxyAPI 集成，升级后会自动将地址和管理密钥迁入管理站点配置，无需重新填写。已有的新配置不会被旧值覆盖；当前选中的其他管理站点也不会被自动切换。

CLIProxyAPI 必须启用管理接口。远程部署还需要允许远程管理，并确保浏览器能够访问该地址。插件支持 HTTP、本机和局域网部署。后端配置方式参见 [CLIProxyAPI 管理接口文档](https://help.router-for.me/cn/management/api)。

## 管理提供商

在 **渠道管理** 页面选择 CLIProxyAPI 后，可以搜索提供商、查看详情、新建、编辑、启用或停用，以及删除单个或多个条目。

支持的 API Key 提供商类型包括：

- OpenAI Compatibility
- Codex
- Claude
- Gemini
- Vertex AI
- xAI
- Gemini Interactions

类型是否可用取决于你的 CLIProxyAPI 版本。管理界面可以编辑上游地址、密钥、模型映射、代理、模型前缀和请求头等字段，并保留未编辑的原生配置。

**模型映射**每行填写一个模型；需要别名时，使用 `模型名 = 别名`。**请求头**每行填写一个 `名称: 值`。API Key 类型的提供商还可以填写排除模型。

OpenAI Compatibility 提供商支持多个 API 密钥。可以逐条添加、查看、替换或移除密钥，并为每把密钥独立设置代理和权重。已有密钥默认隐藏，留空会保留原密钥；查看密钥不会修改配置。权重留空时为 1，非正数表示不参与加权路由。保存时会保留其他密钥及未编辑的原生字段。

## 导入账号密钥或 API 凭据

1. 在 **设置 → 管理站点** 中选中并配置 CLIProxyAPI。
2. 进入 **密钥管理** 或 **API 凭据库**，点击条目操作区中的管理站点导入按钮。
3. 在统一导入弹窗中确认提供商类型、上游地址、密钥和模型，然后提交。
4. 批量导入时，在密钥管理中勾选多个条目，使用管理站点的批量导入入口，先检查预览再执行。

原来位于“导出”菜单中的独立 CLIProxyAPI 入口已合并到管理站点流程。导入后可以继续在渠道管理页面维护这些提供商。

## 常见问题

- **升级后在哪里找原配置？** 前往设置中的管理站点，选择 CLIProxyAPI。原地址和密钥会自动迁入。
- **连接返回 401 或 403？** 检查管理密钥和服务端远程访问设置；客户端 API Key 不能代替管理密钥。
- **某类提供商返回 404？** 检查部署地址、管理接口是否启用，以及后端版本是否支持该类型。
- **提交后提示需要刷新或结果不确定？** 先刷新列表核对服务器上的实际状态，再决定是否重试。其他客户端同时修改配置时，过期编辑可能会被拒绝。
- **是否管理 OAuth 账号或全部服务设置？** 当前管理对象是 API Key 提供商。OAuth 登录、认证文件和全局服务设置仍使用 CLIProxyAPI 自带的管理界面；跨站渠道迁移和自动模型同步尚未接入。
