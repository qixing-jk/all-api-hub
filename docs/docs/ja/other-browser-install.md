# その他のブラウザへのインストールガイド

この記事では、QQブラウザ、360セーフブラウザ、360エクストリームブラウザ、チーターブラウザ、Brave、Vivaldi、OperaなどのブラウザにAll API Hub拡張機能をインストールする方法を説明します。

これらのブラウザの多くは Chromium ベースですが、利用できるインストール方法は同じではありません。ブラウザストアまたは Chrome ウェブストアからインストールできる場合は、まずストア版を使ってください。GitHub の添付ファイルが必要な場合は[自己更新 `.crx`](./chromium-crx-self-update.md) を推奨し、解凍読み込みの `.zip` は `.crx` をインストールできない場合にだけ使います。

::: tip 自分のブラウザは Chromium 系ですか
既定では、はい。Firefox と Safari を除き、拡張機能をインストールできるデスクトップブラウザーは基本的に Chromium 系です。下の表のブラウザーはすべてこの前提でインストール方法を示しています。詳しい説明は [Chromium 自己更新インストール](./chromium-crx-self-update.md) にあります。
:::

## まず違いを確認

- Chrome / Edge / Firefoxユーザー：各ストア版を優先して使用してください。更新がより簡単です。
- Brave / Vivaldi ユーザー：まず Chrome ウェブストアからのインストールを試してください。これらのブラウザは公式に Chrome ウェブストア拡張機能をサポートしています。
- Opera ユーザー：Opera には Opera Add-ons がありますが、All API Hub は現在 Opera Add-ons には単独掲載されていません。まず Chrome ウェブストアを試し、Opera のバージョンやポリシーで利用できない場合は GitHub パッケージを検討してください。
- QQブラウザ、360系ブラウザ、チーターブラウザなどのユーザー：ブラウザ内蔵の拡張機能センターで All API Hub が見つからない場合は、まず[自己更新 `.crx`](./chromium-crx-self-update.md) を試し、`.crx` がブロックされる場合に GitHub の Chrome パッケージを「展開された拡張機能を読み込む」でインストールします。
- Safariユーザー：インストール方法が異なります。XcodeまたはSafari専用パッケージで処理する必要があります。[Safari拡張機能インストールガイド](./safari-install.md)を確認してください。
- モバイルブラウザ：ブラウザによって拡張機能のサポート状況が大きく異なります。モバイル版については、[FAQのモバイルブラウザサポート](./faq.md#mobile-browser-support)を確認してください。

::: warning ヒント
GitHub の添付ファイルでは自己更新 `.crx` を推奨します。ブラウザーがリリースのマニフェストから自動更新するため、パッケージを差し替える必要はありません。stock Chrome / Edge はインストール前に拡張機能の許可リストポリシーを一度設定する必要があります。`.zip` は自動更新されず、更新のたびに再ダウンロードして「再読み込み」または再インストールする必要があるため、`.crx` をインストールできない場合にだけ使います。

ストア版は引き続き第一候補で、これらの設定は不要です。
:::

ブラウザに独自の拡張機能ストアがあっても、All API Hub がそのストアに掲載されているとは限りません。たとえば Opera には Opera Add-ons がありますが、現在は Chrome ウェブストアまたは GitHub パッケージを使ってください。
:::

## GitHub インストールパッケージの準備

Chrome ウェブストア、Edge Add-ons、Firefox Add-ons から直接インストールできる場合、この手順は不要です。以下は GitHub からインストールする必要がある Chromium 系ブラウザ向けです。

### 推奨：自己更新 `.crx`

```text
all-api-hub-chrome.crx
```

ファイル名にバージョンがないのは、`releases/latest` が常に最新の安定版を指すためです（Nightly は `all-api-hub-nightly-chrome.crx`）。インストール後はブラウザーが公開された `updates.xml` から自動で更新するため、パッケージを手動で差し替える必要はありません。

stock Chrome / Edge はインストール前に拡張機能の許可リストポリシーを設定しないと `CRX_REQUIRED_PROOF_MISSING` で失敗するか無効化され、Windows Edge はさらに Active Directory ドメイン参加が必要です。Linux は設定不要で、QQ / 360 などの派生ブラウザは対応状況が異なります。詳しい手順は[Chromium 自己更新インストール](./chromium-crx-self-update.md)を参照してください。

`.crx` と解凍読み込み版は拡張機能 ID が異なるため、データは共有されません。解凍読み込み版を導入済みの場合は、バックアップをエクスポートし、アンインストールしてから `.crx` をインストールし、最後にバックアップを復元してください。

### 代替：解凍読み込み `.zip`

`.crx` をインストールできない場合（ブラウザが外部拡張機能を許可しない、セキュリティポリシーでブロックされるなど）に ZIP を使用します。自動更新はされません：

1. [最新リリースバージョン](https://github.com/qixing-jk/all-api-hub/releases/latest)を開きます。
2. 添付ファイルからChrome版の圧縮ファイルをダウンロードします：

```text
all-api-hub-<version>-chrome.zip
```

例：

```text
all-api-hub-3.32.0-chrome.zip
```

3. 圧縮ファイルを、`D:\Extensions\all-api-hub\` のような固定ディレクトリに解凍します。
4. 選択した拡張機能ディレクトリに `manifest.json` ファイルが直接見えることを確認します。

::: tip ディレクトリの選択
拡張機能を読み込む際は、`manifest.json` を含むディレクトリを選択してください。「マニフェストファイルが見つかりません」または「manifest.json が存在しません」というエラーが表示される場合は、通常、外側の親ディレクトリを選択しすぎている可能性があります。
:::

<a id="desktop-browser-common-flow"></a>

## その他のデスクトップブラウザでの手動読み込み手順

ストア版を使えないものの、Chrome 拡張機能ディレクトリの読み込みには対応しているデスクトップブラウザ向けです。

1. ブラウザの拡張機能管理ページを開きます。
   - アドレスバーに `chrome://extensions/` と入力して試してください。
   - 開けない場合は、ブラウザメニューから「拡張機能」、「拡張機能」、「プラグイン管理」、または「アプリ管理」を選択してください。
2. `開発者モード` をオンにします。
3. 「展開された拡張機能を読み込む」をクリックします。
4. 先ほど解凍し、`manifest.json` を含むディレクトリを選択します。
5. インストール後、拡張機能リストで `All API Hub` が有効になっていることを確認します。
6. ツールバーにアイコンが表示されない場合は、拡張機能ボタンからAll API Hubをツールバーに固定します。
7. インストール前に転送ステーションページを開いていた場合は、これらのページをリロードしてから自動認識を使用してください。

<a id="qq-browser"></a>

## QQブラウザのインストール

QQブラウザのデスクトップ版では、通常Chrome版の圧縮パッケージを使用して手動で読み込むことができます。

### 1. 拡張機能管理ページへのアクセス

いずれかの方法を選択してください：

- アドレスバーに `qqbrowser://extensions` と入力
- 上記のアドレスが利用できない場合は、`chrome://extensions/` を試す
- 右上メニューから「拡張機能」、「拡張機能」、「アプリセンター」などを選択し、「拡張機能の管理」を開く

### 2. 開発者モードの有効化

拡張機能管理ページで `開発者モード` のスイッチを見つけてオンにします。バージョンによって、このオプションはページの右上、ページ下部、または「高度な管理」セクションにある場合があります。

### 3. 拡張機能ディレクトリの読み込み

1. 「展開された拡張機能を読み込む」をクリックします。
2. 解凍した `all-api-hub-<version>-chrome` ディレクトリを選択します。
3. インストール後、拡張機能が有効になっていることを確認します。

### 4. よくある問題への対応

- ページに `開発者モード` がない場合：現在のQQブラウザのバージョンでは外部拡張機能のインストールが制限されている可能性があります。最新のデスクトップフルバージョンにアップグレードするか、Chrome / Edgeの使用を検討してください。
- 「QQブラウザストアからのものではありません」というメッセージが表示される場合：「展開された拡張機能を読み込む」を優先して使用してください。圧縮ファイルを直接ドラッグアンドドロップしないでください。
- 拡張機能がインストールされているのにページが認識しない場合：転送ステーションのページをリロードし、ページがブラウザの互換モードや特殊なセキュリティモードになっていないことを確認してください。

<a id="browser-360"></a>

## 360系ブラウザのインストール

360セーフブラウザと360エクストリームブラウザはどちらもChromium拡張機能をサポートしている可能性がありますが、アクセス名やセキュリティ通知はバージョンによって異なります。

### 1. エクストリームモードの使用を確認

360セーフブラウザには、「エクストリームモード/互換モード」などの異なるレンダリングエンジンモードがあります。All API HubはChromium拡張機能であるため、認識が必要なサイトページではエクストリームモードを使用することをお勧めします。

アドレスバーの近くに `稲妻` / `e` などのレンダリングエンジン切り替えアイコンが表示されている場合は、`エクストリームモード` に切り替えてから拡張機能を使用してください。

### 2. 拡張機能管理ページへのアクセス

いずれかの方法を選択してください：

- アドレスバーに `chrome://extensions/` と入力
- 右上メニューから「拡張機能」、「拡張機能管理」、「プラグイン管理」、または「アプリ管理」を選択
- `高度な管理` エントリがある場合は、まず高度な管理に入り、デベロッパー関連のオプションを有効にする

### 3. 開発者モードの有効化と読み込み

1. `開発者モード` をオンにします。
2. 「展開された拡張機能を読み込む」をクリックします。
3. 解凍した `all-api-hub-<version>-chrome` ディレクトリを選択します。
4. インストール後、All API Hubを有効にし、必要に応じてツールバーに固定します。

### 4. よくある問題への対応

- ブラウザのセキュリティポリシーが `.crx` をブロックする場合：展開して読み込む方法に切り替えてください。`.zip` ファイルを直接ドラッグアンドドロップしないでください。
- ブラウザを再起動すると拡張機能が無効になる場合：拡張機能管理ページで手動で有効にしてください。それでも無効になる場合は、Chrome / Edgeへの切り替え、またはブラウザのセキュリティポリシーを確認することをお勧めします。
- 一部のウェブページで拡張機能が機能しない場合：そのページが互換モードに切り替わっていないことを確認し、インストール前に開いていたページをリロードしてください。

<a id="liebao-browser"></a>

## チーターブラウザのインストール

チーターブラウザでは、組み込みの拡張機能管理ページからChrome版の圧縮パッケージを手動で読み込むことができます。

### 1. 拡張機能管理ページへのアクセス

アドレスバーに以下を入力します：

```text
liebao://extensions/
```

このアドレスが利用できない場合は、ブラウザメニューから「拡張機能」、「拡張機能」、または「プラグイン管理」を選択してください。

### 2. 開発者モードの有効化

拡張機能管理ページで `開発者モード` をオンにします。

### 3. 拡張機能ディレクトリの読み込み

1. 「展開された拡張機能を読み込む」をクリックします。
2. 解凍した `all-api-hub-<version>-chrome` ディレクトリを選択します。
3. インストール後、拡張機能が有効になっていることを確認します。

### 4. よくある問題への対応

- ブラウザに「このウェブサイトの設定を変更しますか？」のようなプロンプトが表示された場合：まず「設定を保持」を選択し、ブラウザがホームページやタブの設定を変更しないようにしてください。
- 拡張機能がインストールされても機能しない場合：インストール前に開いていた対象サイトのページをリロードしてください。
- 現在のバージョンで開発者モードまたは読み込みエントリが見つからない場合：チーターブラウザのデスクトップ版にアップグレードするか、Chrome / Edgeの使用を検討してください。

## Brave / Vivaldi / Opera のインストール

これらのブラウザは通常 Chrome ウェブストアを利用できます。まず対象ブラウザで [All API Hub の Chrome ウェブストアページ](https://chromewebstore.google.com/detail/lapnciffpekdengooeolaienkeoilfeo) を開き、インストールを試してください。

- Brave は公式に Chrome ウェブストアからの拡張機能インストールをサポートしています。
- Vivaldi は公式に Chrome ウェブストア拡張機能をサポートしています。インストールボタンが表示されない場合は、Vivaldi の Google Extensions / Web Store 関連設定を確認してください。
- Opera には Opera Add-ons があり、Chrome 拡張機能にも対応しています。All API Hub は現在 Opera Add-ons には単独掲載されていないため、まず Chrome ウェブストアを使ってください。

ストアインストールに失敗した場合は、まず自己更新 `.crx` を試し、それでも無理なら以下の拡張機能管理ページから解凍ディレクトリを読み込みます：

| ブラウザ | 拡張機能管理ページ |
|---|---|
| Brave | `brave://extensions/` |
| Vivaldi | `vivaldi://extensions/` |
| Opera | `opera://extensions/` |
| その他のChromiumブラウザ | `chrome://extensions/` を優先して試してください |

拡張機能管理ページにアクセスしたら、[手動読み込み手順](#desktop-browser-common-flow)に従って開発者モードを有効にし、解凍したディレクトリを読み込んでください。

<a id="update-extension"></a>

## 拡張機能の更新

`all-api-hub-chrome.crx` はブラウザーがリリースのマニフェストから自動更新するため、手動操作は不要です。`chrome://extensions/` の「更新」で今すぐ確認できます。ストア版、GitHub Stable、Nightly の違いについては、先に [インストール方法と更新について](./extension-update-install.md) を確認してください。

解凍読み込みの `.zip` 版は自動更新されません。更新する場合は以下の手順に従ってください：

1. [最新リリースバージョン](https://github.com/qixing-jk/all-api-hub/releases/latest)を開きます。
2. 新しい `all-api-hub-<version>-chrome.zip` をダウンロードします。
3. 元の固定ディレクトリに解凍するか、新しいバージョンディレクトリに解凍します。
4. 拡張機能管理ページを開きます。
5. 元のディレクトリを引き続き使用する場合は、All API Hubのカードにある「再読み込み」をクリックします。
6. 新しいディレクトリに変更した場合は、まず古いバージョンを削除し、次に新しいディレクトリを読み込みます。

::: warning 注意
拡張機能ディレクトリをシステムのテンポラリディレクトリ、ダウンローダーのキャッシュディレクトリ、または削除される可能性のあるソフトウェアのディレクトリに置かないでください。ディレクトリが削除または移動されると、ブラウザはその拡張機能を読み込めなくなります。
:::

## アンインストール

1. ブラウザの拡張機能管理ページを開きます。
2. `All API Hub` を見つけます。
3. 「削除」、「アンインストール」、または有効化スイッチをオフにします。
4. ローカルの解凍ディレクトリを削除します。

## よくある質問

### `.crx`、Chromeパッケージ、Firefox / Safariパッケージのどれをダウンロードすべきですか？

GitHub 版が必要な Chromium ブラウザでは、まず自己更新パッケージをダウンロードしてください：

```text
all-api-hub-chrome.crx
```

`.crx` をインストールできない場合だけ、以下をダウンロードします：

```text
all-api-hub-<version>-chrome.zip
```

Firefoxの`.xpi` / Firefoxパッケージや、SafariのXcodeバンドルはダウンロードしないでください。

### `.zip` ファイルを直接インストールできますか？

通常は推奨しません。まず解凍し、「展開された拡張機能を読み込む」で`manifest.json`を含むディレクトリを選択してください。

### インストールに成功した後も自動認識が失敗するのはなぜですか？

一般的な原因は以下の通りです：

- インストール前に目的のサイトページを開いていた場合、ページをリロードする必要があります。
- 目的のサイトのログイン状態が無効になっている場合、まず同じブラウザで再ログインする必要があります。
- ブラウザが互換モードまたはセキュリティモードに切り替わっており、Chromium拡張機能がページに注入されていない。
- 現在のブラウザが拡張機能APIを完全にサポートしていない場合、Chrome / Edgeで再現を確認してください。

### サイドバーのエントリが利用できない場合はどうすればよいですか？

一部のブラウザは、Chrome / Edgeのサイドバー機能をサポートしていません。このような場合は、拡張機能のポップアップまたは設定ページを使用してアカウント管理を行ってください。コア機能はサイドバーに依存しません。
