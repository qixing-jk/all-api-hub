# モデル一覧と価格比較

> モデル一覧は、現在のデータソースが提供するモデルカタログを読み取り、絞り込み、比較、検証するためのページです。アカウントと API 認証情報のモデル、価格、利用可否をまとめ、現在読み込まれて比較可能なデータと実際の用途に基づいて、モデルとデータソースを選ぶために役立ちます。

## 機能の概要

- 🔍 **3 種類のデータソース**：すべてのアカウント、指定アカウント、API 認証情報（API Credential Profile）。
- 💰 **アカウント間の価格比較**：異なるアカウントの同じモデルをまとめ、現在利用可能な価格を統一基準で比較します。
- 🎯 **用途に近い見積もり**：通常のチャット、コード補完、コーディングエージェントなどの用途を選ぶか、入力、出力、キャッシュの割合を調整できます。
- 🏷️ **検索、絞り込み、並べ替え**：モデル名や説明を検索し、ベンダー、課金方式、能力、グループ、検証結果で絞り込み、価格や遅延などで並べ替えます。
- ✅ **モデル検証**：単体検証と一括検証はいずれも 1 回のプローブで、モデルまたはエンドポイントが現在利用可能か、CLI と互換性があるかを確認します。
- 📦 **モデルに対応するキー**：互換性のあるキーを選ぶか、対応している場合はそのモデルに制限した Token を作成します。

## アクセス方法

1. 拡張機能のポップアップで **`モデル一覧`** アイコンをクリックします。
2. フルページ表示では、左側の **インターフェース** カテゴリから **`モデル一覧`** を開きます。
3. アカウント管理または API 認証情報ライブラリで **`モデル一覧で開く`** をクリックすると、対応するデータソースを直接開けます。

## 主な操作

### 1. データソースを選択

ページ上部の **`データソースを選択`** ドロップダウンで切り替えます。

- **すべてのアカウント**：追加済みの全サイトアカウントを集約し、サイト間で比較します。
- **指定アカウント**：1 つのアカウントのモデルカタログを表示します。
- **API 認証情報**：API 認証情報ライブラリに保存した `Base URL + API Key` でモデルカタログを読み取ります。サイトアカウントを作成する必要はありません。

> 「プロバイダーカタログ / パーソナライズドカタログ」は、一部のアカウント内部のデータ範囲を示すもので、上部の独立したデータソースではありません。

データソースごとに提供できる情報が異なります。

| データソース | 価格 / 倍率 / グループ | 説明 |
|------|------|------|
| すべてのアカウント | 各アカウントの能力による | 集約比較に使用 |
| 指定アカウント | アダプターによる | 価格、倍率、グループを提供するソースもあれば、モデルカタログだけのソースもあります |
| API 認証情報 | 通常は提供されない | 主にモデル検出と検証に使用 |

### 2. 検索、絞り込み、並べ替え

- **検索**：モデル ID、表示名、説明に一致します。サイト名は検索しません。
- **ベンダータブ**：解析されたベンダー別に表示します。「未分類」も含まれます。
- **課金方式**：すべて / Token（従量課金）/ 1 回ごと。
- **モデル能力**：画像、音声、動画、PDF、推論、ツール呼び出し、構造化出力など。ソースが能力情報を提供する場合だけ表示されます。
- **グループフィルター**：アカウントグループで絞り込みます。すべてのアカウント表示では、比較に参加するグループをアカウント別に選択できます。
- **テスト結果**：成功 / 失敗 / 未テスト。
- **並べ替え**：既定、価格の昇順、価格の降順、テスト遅延の昇順。すべてのアカウント表示では「同じモデルの最安値を優先」も利用できます。
- **価格比較条件**：価格で並べ替える場合に用途を選ぶか、入力、出力、キャッシュ読み取り、キャッシュ書き込みの割合を調整します。
- **表示内容**：実際のチャージ金額、エンドポイント種別。

> 絞り込みと並べ替えの操作は、現在のデータソースが対応している場合だけ表示されます。すべてのデータソースに全操作があるとは限りません。

### 3. 価格を比較

**`ワンクリック価格比較`** をクリックすると、現在のフィルターを解除し、すべてのアカウントへ切り替え、同じモデルの最安値を優先して並べ替えます。

- **比較条件を設定**：用途に近いシナリオを選ぶか、入力、出力、キャッシュ読み取り、キャッシュ書き込みの割合を調整します。
- **比較可能な価格を確認**：同じ課金方式で、現在の条件に必要な価格データをすべて提供できる価格だけが順位付けに参加します。その他の価格は **`現在の条件では比較対象外`** に残り、不足データを確認できます。
- **価格詳細を確認**：Token 従量課金モデルでは、100 万 Token あたりの入力、出力、キャッシュ価格が表示されます。1 回ごとの課金モデルでは、1 リクエストあたりの価格が表示されます。モデルを展開するとグループ別の価格も確認できます。

価格ラベルの意味：

- **見積価格**：利用可能な価格表とグループ情報から計算され、絞り込みに利用できます。実際の請求はサービス提供者の情報を基準にしてください。
- **最安値**：現在のフィルターと比較条件で比較可能な価格のうち、最も低いものです。
- **最適グループ**：比較可能なグループのうち、1 つだけが最安値の場合に表示されます。最安値が同額の場合は、1 つを指定しません。

> - 価格比較は**ローカル計算**で、現在読み込まれ、有効で比較可能な価格だけを対象にします。公式な保証、リアルタイムの全量データ、「インターネット上の最安値」を示すものではありません。
> - 欠落または不正な価格は**比較不可**で、`0` や既定価格として扱いません。サイトが明示的に 0 を返す場合、そのモデルは実際に無料の可能性があります。
> - サイトの価格 API、公式カタログ、見積もりなど、価格ソースは異なる場合があります。ページでは可能な限りソースと精度を表示します。

### 4. グループ切り替えと最適グループ

データソースが複数のユーザーグループに対応している場合、グループフィルターで比較に参加するグループを限定し、モデルを展開してグループ別価格を確認できます。グループは実際の単価に直接影響します。価格を利用する前に、そのアカウントが該当グループを利用できることを確認してください。

**「最適グループ」は現在のフィルターと比較条件に基づくローカル計算結果**であり、サービス提供者の公式推奨や長期保証ではありません。

### 5. 1 モデルを検証

モデルカードの検証アイコンをクリックします。

- **API を検証**：1 回のプローブを送信し、そのモデルまたはエンドポイントが現在利用可能で、応答が期待どおりかを確認します。
- **CLI 互換性を検証**：ストリーミングやテキスト生成への対応など、CLI ツールに適しているかを評価します。

> - 検証は**1 回のプローブ**です。長期的な利用可能性や永続的な失敗を意味しません。
> - CLI 互換性検証は**実際の外部 CLI を起動しません**。プロトコルレベルのシミュレーションだけを行います。

### 6. 一括テスト

ツールバーの **`一括テスト`** をクリックして **`モデルを一括テスト`** を開きます。

1. **`テスト項目`**を選びます。エンドポイント種別から自動判定するか、テキスト生成、ツール呼び出し、構造化出力などを明示的に選択できます。
2. **`実行するモデル`**で、テストするモデルを選択または全選択します。
3. **`一括テストを開始`**をクリックします。テストは最大 5 件の同時実行でキュー処理されます。いつでも **`テストを停止`**でき、それまでに得られた部分結果は保持されます。
4. ダイアログには合計、成功、失敗、スキップの件数が表示されます。

> 適用できないテスト項目は自動的にスキップされます。結果はその時点のプローブ結果であり、参考情報です。

### 7. モデルに対応するキー

モデルカードのキーボタンをクリックして **`モデルに対応するキー`** を開きます。

- 現在のモデルと互換性のあるキーを選択します。グループまたは能力が一致するキーだけが表示されます。
- 対応している場合、**`クイック作成`**でそのモデルに制限した新しい Token を作成するか、**`カスタム作成`**を使用できます。

> この操作で変更するのはキー / Token です。モデルカタログ自体は編集しません。

### 8. データを更新

**`データを更新`**をクリックすると、現在のデータソースへ再度リクエストし、関連するローカルキャッシュを無効にします。更新動作はデータソースごとに異なり、更新後のデータはソースの応答を基準にします。

## 一覧の操作項目

| 設定 | 説明 |
|------|------|
| **データソース** | すべてのアカウント / 指定アカウント / API 認証情報 |
| **検索** | モデル ID、表示名、説明をあいまい検索 |
| **ベンダータブ** | ベンダー別に表示 |
| **課金方式** | すべて / Token（従量課金）/ 1 回ごと |
| **モデル能力** | 画像、音声、動画、PDF、推論、ツール呼び出しなど。ソースが提供する場合に表示 |
| **グループフィルター** | アカウントグループで絞り込み |
| **テスト結果** | 成功 / 失敗 / 未テスト |
| **並べ替え** | 既定、価格の昇順 / 降順、テスト遅延、同じモデルの最安値を優先 |
| **価格比較条件** | 用途、または入力、出力、キャッシュ読み取り、キャッシュ書き込みの割合 |
| **表示内容** | 実際のチャージ金額、エンドポイント種別 |

## 機能の範囲

- モデル一覧では、リモートモデルの**追加、編集、削除、有効化、無効化、一括同期を行いません**。
- セルフホスト型サイトのモデル同期は別機能です。[Managed Site モデル同期](./managed-site-model-sync.md)を参照してください。

## よくある質問

| 質問 | 回答 |
|------|------|
| モデル価格が 0、または比較に参加できないのはなぜですか？ | サイトが明示的に 0 を返す場合、そのモデルは実際に無料の可能性があります。価格データが不完全な場合は比較不可として表示され、無料として扱いません。 |
| サイト間の価格比較はどのように計算されますか？ | 現在読み込まれ、有効で比較可能な価格をローカルで計算します。ページに表示されるソースと精度を確認し、実際の料金は各サイトの公開価格を基準にしてください。 |
| 「現在の条件では比較対象外」と表示されるのはなぜですか？ | キャッシュ読み取り価格など、現在の条件で必要な価格が不足しています。別の用途を選ぶ、割合を調整する、または価格を展開して利用可能な情報を確認してください。 |
| 検証結果が失敗または不明になるのはなぜですか？ | 検証は 1 回のプローブで、権限、モデル制限、レート制限などの影響を受けます。最終的には対象ツールでの実際の動作を基準にしてください。 |
| アカウントに価格や倍率がないのはなぜですか？ | データソースが価格、倍率、グループ情報を提供しない場合があります。たとえば API 認証情報は、通常モデル検出と検証だけに対応します。 |
