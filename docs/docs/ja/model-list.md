# モデルリストと価格比較

> アカウントと API 認証情報に含まれるモデル、料金、利用可否をまとめ、実際の用途に合わせて絞り込み、比較できます。

## 機能の概要

- 💰 **アカウント横断の料金比較**: 複数のアカウントや API 認証情報にある同じモデルを、共通の基準で比較できます。
- 🎯 **使い方に合わせた見積もり**: 一般チャット、コード補完、コーディング Agent などの利用シーンを選ぶか、入力、出力、キャッシュの利用割合を調整できます。
- 🔍 **多次元の詳細フィルタリング**: サイトソース、API認証情報、プロバイダー（OpenAI、Anthropicなど）、課金モード、タグによる組み合わせフィルタリングをサポート。
- ✅ **一括可用性検証**: モデルの接続テスト、トークンの互換性チェック、CLIプロキシの可用性検証をサポート。
- 📊 **課金の透明化**: 「トークン課金（Tokens）」と「リクエスト課金（Per Call）」を明確に区別し、利用可能な場合は入力、出力、キャッシュの実際の単価を表示します。

## アクセス方法

1. 拡張機能のポップアップの左下にある **「モデルリスト」** アイコンをクリックします。
2. または、 **設定 → モデル管理** からアクセスします。

## コア操作ガイド

### 1. データソースの選択

ページ上部のセレクターで、異なるデータソースを切り替えることができます：

- **すべてのアカウント**: 追加したすべてのサイトアカウントを集計し、サイト間比較を有効にします。
- **特定のアカウント**: 指定したサイトの完全なモデルカタログを表示します。
- **API認証情報**: 独立したAPI認証情報（サイトアカウント不要）でサポートされているモデルを表示します。

### 2. 料金を比較する

アカウントをまたいで比較するには、 **「価格を比較」** をクリックします。すべてのアカウントに切り替わり、同じモデルでは料金の安い候補が優先して並びます。

- **比較条件を設定する**: 用途に近い利用シーンを選ぶか、入力、出力、キャッシュ読み取り、キャッシュ書き込みの割合を調整します。
- **比較可能な料金を確認する**: 同じ課金方式で、現在の比較条件に必要な料金データがそろっている候補だけを同じ基準で順位付けします。それ以外の候補も **「現在の条件では比較対象外」** に残り、不足している料金項目を確認できます。
- **料金の内訳を確認する**: トークン課金では、入力、出力、キャッシュの料金を 100 万トークン単位で表示します。リクエスト課金では、1 回あたりの料金を表示します。モデルを展開すると、グループごとの料金も確認できます。

料金ラベルは次のように読み取れます：

- **推定**: 利用可能な料金表とグループ情報から計算した値です。候補の絞り込みに使い、実際の請求はサービス提供元で確認してください。
- **最安値**: 現在の絞り込みと比較条件で、比較可能な候補の中で最も安い料金です。
- **最安グループ**: あるグループがほかのグループより明確に安い場合に表示します。最安料金が同額なら、1 つのグループを最安とは表示しません。

### 3. グループの切り替えとシミュレーション

サイトが複数のユーザーグループ（例：`default`、`vip`、`svip`）をサポートしている場合、グループフィルターで比較対象を絞り、モデルを展開して各グループの料金を確認できます。

> 💡 **ヒント**: グループによって実際の単価が変わります。候補を利用する前に、アカウントが該当グループを利用できることを確認してください。

### 4. モデルの検証

モデルカードの右側にある検証アイコンをクリックします：

- **モデルの検証**: 軽量なリクエストを送信して、モデルが現在本当に利用可能かどうかを確認します。
- **CLI互換性の検証**: モデルがストリーミング出力をサポートしているか、コマンドラインツールから正常に呼び出せるかをテストします。
- **一括検証**: ツールバーの **「一括検証」** をクリックすると、現在フィルタリングされているすべてのモデルのテストをキューに入れます。また、チェックボックスを使用して複数のモデルを手動で選択し、選択したセットに対してのみ検証を実行することもできます。

## リストコントロールオプション

| オプション | 説明 |
|------|----------|
| **検索ボックス** | モデルID（例：`gpt-4o`）またはサイト名によるあいまい検索をサポート。 |
| **課金モード** | 「トークン課金」または「リクエスト課金」でモデルをフィルタリング。 |
| **プロバイダーフィルター** | OpenAI、Anthropic、Google、Metaなどのベンダーのモデルを素早く特定。 |
| **並べ替え** | デフォルト順、同一モデルの最安値優先、料金の昇順・降順、検証時間順を選べます。 |
| **料金比較の条件** | 料金順で並べるときに、利用シーンを選ぶか、入力、出力、キャッシュの割合を調整できます。 |
| **表示設定** | 人民元価格とエンドポイントタイプを表示するかどうかを設定できます。 |

## よくある質問

| 質問 | 解決策 |
|------|----------|
| モデルの料金が 0、または比較対象外になるのはなぜですか？ | サイトが料金を 0 と明示している場合は、無料の可能性があります。必要な料金データが不足している場合は、無料とは扱わず、比較対象外として表示します。 |
| サイト間比較の為替レートはどのように計算されますか？ | 拡張機能には、比較基準を統一するために 1 USD = 7.3 CNY の固定レート（New APIの慣例を参照）が組み込まれています。 |
| 「現在の条件では比較対象外」と表示されるのはなぜですか？ | 現在の利用割合で必要な料金項目（キャッシュ読み取り料金など）を価格ソースが提供していません。別の利用シーンを選ぶか割合を調整し、候補を展開して利用可能な料金を確認してください。 |
| 検証結果が「不明」と表示されるのはなぜですか？ | APIキーにそのモデルを呼び出す権限があるか、またはサイトが現在レート制限（Rate Limit）にかかっていないか確認してください。 |
