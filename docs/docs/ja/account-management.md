# アカウント管理

> このガイドでは、アカウント追加後の整理、メンテナンス、一括操作について説明します。新しいアカウントの追加や手動入力の方法については、[アカウントの追加](./add-account.md)を参照してください。

## アカウントを追加する

まず自動認識を試してください。失敗した場合は、New API、Sub2API、OpenRouter などのサイト種別に必要な情報を手動入力できます。

- [アカウント追加の完全なガイドを見る](./add-account.md)
- [手動追加の説明へ移動](./add-account.md#manual-addition)

## 1. 重複アカウントのクリーンアップ

誤って重複アカウントを追加した場合は、組み込みのクリーンアップツールを使用できます。

1. **「アカウント管理」**を開き、上部の **「重複アカウントをスキャン」**をクリックします。
2. **「重複アカウントのクリーンアップ」**で結果を確認します。異なるアドレスの**重複候補**は個別に確認する必要があり、一括整理には含まれません。
3. 拡張機能は **URL のオリジン + ユーザー ID** でアカウントをグループ化します。同じ Management Key を使用するアカウントをグループ化する場合もあります。
4. **3 種類の保持方法**から 1 つを選ぶか、残すアカウントを手動で選択します。
5. 削除前にクリーンアップを確認します。

## 2. アカウントの整理と並べ替え

アカウント数が増えた場合は、次の機能を使って一覧を整理できます。

### 2.1 タグ

- アカウントに `仕事`、`個人`、`中継`、`公式` などのタグを追加します。
- パネル上部でタグを選び、アカウントを絞り込めます。
- タグはブックマークや API 認証情報ライブラリと共有され、全体で名前を変更できます。

### 2.2 固定

- アカウント右側の **「…」**メニューを開き、**「アカウントを固定」**を選択します。
- 固定済みのアカウントは、同じメニューから **「固定を解除」**できます。
- 固定済みアカウントには行内にピン状態が表示されます。
- 同じ閲覧優先段階では固定アカウントが先になります。現在のサイトや関連ページが開いているアカウントは、その他の固定アカウントより先に表示されることがあります。無効なアカウントは常に末尾です。

### 2.3 並び順の優先設定

- **設定 → アカウント管理 → 並び順の優先設定**で、現在のサイトと関連ページが開いているアカウントの優先表示を個別に設定できます。変更は自動保存されます。
- 一覧の **並び替え** メニューでアカウント名、残高、今日の消費・収入、チェックイン要件、健全性、カスタムチェックイン・引き換えリンク、作成日時を選び、方向を切り替えます。
- **既定の並び順に戻す**は、選択した項目による並べ替えを解除します。閲覧優先設定と保存済みの手動順序は維持されます。
- 設定ページで **順序を調整** を押すとドラッグできます。変更は自動保存され、固定、通常、無効の各グループ内でのみ移動できます。
- 検索と手動並べ替えでは閲覧中のサイトの優先表示は適用されません。詳しくは[並び順の優先設定](./sorting-priority.md)を参照してください。

### 2.4 残高と今日の収益の集計

- アカウントの追加または編集時に **「合計残高から除外」**を有効にすると、ポップアップ、アカウント一覧、共有概要スナップショットの合計残高に含まれなくなります。アカウントの更新、チェックイン、一覧表示には影響しません。
- アカウントの収益を当日の集計に含めない場合は、**「今日の収益から除外」**を有効にします。ポップアップ、アカウント一覧、共有概要スナップショットの今日の収益合計だけに影響し、アカウントは非表示にならず、更新やチェックインも停止しません。

### 2.5 アカウントごとの「…」メニュー

アカウント右側の **「…」**メニューには、キー、モデル、更新、チェックイン、関連ページ、共有、アカウント管理の操作があります。表示される項目はアカウントの状態とサイトの対応機能によって異なり、チェックインの問題報告や対応リクエストも行えます。

無効なアカウントのメニューには、**アカウントを有効化**と**削除**のみが表示されます。

::: tip 「クイックチェックイン」と「チェックイン設定」
- **クイックチェックイン**は、そのアカウントの組み込みチェックインプロバイダーをすぐに呼び出します。全体の毎日スケジュールが無効でも実行できますが、アカウントが有効かつ認識済みで、アカウント単位の「毎日の自動チェックインを有効化」がオンになっている必要があります。また、サイト種別に組み込みプロバイダーがあり、認証情報が使用可能である必要があります。
- **チェックイン設定**はアカウント編集フォーム内のセクションです。組み込みプロバイダーに対応するアカウントには「毎日の自動チェックインを有効化」が表示され、すべてのアカウントで外部チェックインサイト URL を任意入力できます。従来の「チェックイン検出」スイッチはなく、チェックイン状態はアカウントの更新または認識時に自動取得されます。
- 完全な動作は[自動チェックイン](./auto-checkin.md)を参照してください。
:::

## 3. ヘルスステータスとエラーコード

拡張機能はアカウントの接続状態を監視します。アカウントカードに警告や異常が表示される主な原因は次のとおりです。

- **401 Unauthorized**：ログインが失効したか、Access Token が無効です。
- **429 Too Many Requests**：サイトのレート制限に達しました。拡張機能が自動再試行をキューに入れます。
- **403 Forbidden**：Cloudflare の保護が作動した可能性があります。[Cloudflare 認証ヘルパー](./cloudflare-helper.md)を参照してください。

アカウントカードのヘルスステータスアイコンをクリックすると、詳細なエラー情報を確認できます。その他の対処方法は[よくある質問](./faq.md)を参照してください。

## 4. 一括操作

アカウント管理で対象を選択すると、以下の操作を使用できます。検索やタグを変更しても選択は保持されるため、削除や無効化の前に選択済みの全アカウントを確認し、不要な項目を選択解除してください。

- **現在の結果を選択**：現在の検索とタグの条件に一致するアカウントをすべて選択します。
- **現在の結果の選択を解除**：現在の絞り込み結果に含まれるアカウントだけを選択解除します。
- **すべての選択を解除**：選択中のすべてのアカウントを解除します。
- **選択項目を無効化**：選択したすべてのアカウントを無効にします。
- **招待リンクをコピー**：選択したアカウントの招待リンクをコピーします。
- **選択項目を削除**：確認後、選択したすべてのアカウントを削除します。
- **一括モードを終了**：一括操作モードを終了します。

- アカウントが選択されていない場合、対応する操作は使用できません。選択すると有効になります。
- 「ブックマークから取り込む」は独立した入口で、選択式の一括ツールバーには含まれません。手順は[アカウントの追加](./add-account.md)を参照してください。
