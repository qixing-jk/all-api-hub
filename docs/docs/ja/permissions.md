# 権限管理（オプション権限）

権限管理では、拡張機能のオプション権限を確認、許可、取り消しできます。アカウントの更新、補助ツール、システム通知、ブックマークからのインポートなど、使う機能に必要な権限を許可してください。許可していない機能は制限される場合がありますが、ほかの機能は引き続き利用できます。

## 設定へのアクセス

拡張機能の **設定 → 権限** を開くと、ブラウザで利用できる権限と現在の状態を確認できます。対応する権限はブラウザによって異なるため、ページに表示される一覧を確認してください。

## 権限が必要になる場面

| 権限 | 用途と利用場面 |
| --- | --- |
| Cookie へのアクセス | ログイン状態の確認やアカウント更新時に、対象サイトで必要な Cookie を読み取ります。 |
| ネットワークリクエストのルール、アクセス、変更 | 一時ページでの認証やアカウント更新時に、現在のアカウントに必要なリクエスト情報を補います。Chrome、Edge、Firefox では権限名が異なります。 |
| クリップボードの読み取り | コピーした内容から、引き換えコードアシスタントや AI API テストがコードや API 情報を認識するために使います。 |
| システム通知 | バックグラウンドタスクの結果などをブラウザの通知で知らせます。通知設定で対象のイベントも選択してください。 |
| ブラウザのブックマーク | ブックマークからサイトをインポートするときに、保存された URL を読み取ります。 |

使わない機能の権限は、オフのままで構いません。サイト認証や更新に問題がある場合は、機能の案内に従って必要な権限を確認してください。通常の更新のために、すべての権限を許可する必要はありません。サイト認証の設定は [Cloudflare シールド回避ヘルパー](./cloudflare-helper.md) を参照してください。

## 許可、取り消し、状態の更新

1. 必要な権限の **許可（推奨）** をクリックします。
2. ブラウザの確認ダイアログが表示されたら確認し、ページが **許可済み** になったことを確かめます。ダイアログが表示されない権限もあるため、ページの状態で確認してください。
3. 不要になった権限は **取り消し** をクリックします。関連する機能を再び使う際には、再度許可が必要になる場合があります。

**確認中…** と表示されている間は、状態の読み取りが終わるまでお待ちください。ブラウザの設定で権限を変更した場合は、**状態を更新** をクリックして再確認できます。

## データの保存とプライバシー

アカウントとサイトの設定は、既定でブラウザ内に保存されます。拡張機能は `unlimitedStorage` を含む組み込みのローカルストレージ権限で設定や履歴を保存するため、権限管理ページで個別に有効にする必要はありません。このストレージ権限自体による権限の警告はありません。

使用量履歴と残高履歴は、それぞれの設定で指定した日数だけ保持され、保存期間を過ぎると自動的に削除されます。ほかの履歴やキャッシュにも、それぞれの削除ルールがあります。利用できる容量は端末の空き容量に依存します。バックアップについては [WebDAV バックアップと自動同期](./webdav-sync.md) を参照してください。

オプション権限を許可するだけでは、対応する機能は有効になりません。拡張機能は、利用する機能や設定に応じて必要なデータへアクセスします。残高更新、サイト API へのアクセス、バックアップと同期、匿名製品統計などでは、それぞれに必要なネットワーク通信が発生します。

## トラブルシューティング

- **「許可」をクリックしてもダイアログが表示されない**：まず「許可済み」になっていないか確認してください。未許可の場合はブラウザの権限通知を確認し、その機能を使う際に再試行してください。
- **権限が確認できない、または一覧にない**：ブラウザがその権限に対応しているか確認し、状態の更新を試してください。
- **許可してもサイト認証や更新が失敗する**：サイト認証の設定、ログイン状態、ネットワーク接続も確認してください。[Cloudflare シールド回避ヘルパー](./cloudflare-helper.md) も参照できます。
