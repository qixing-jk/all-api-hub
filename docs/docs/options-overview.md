# 总览（设置页主仪表盘）

> 打开 All API Hub 的设置页，看到的第一个页面就是"总览"。它把你的账号、凭据、用量、自动化任务和配置状态汇总在一屏，让你一眼看清"现在情况怎么样、还有哪些事情要处理"。
>
> **页面副标题**：查看账号、密钥、用量和自动任务的当前状态。

## 30 秒速览

如果你是第一次打开总览，按这个顺序看最省心：

1. **顶部 4 个数字卡片**（账号 / 凭据库 / 今日用量 / 待处理）—— 快速摸清整体情况。
2. **"需要处理"区** —— 如果有红黄提示，点"打开"去解决。
3. **"统一 API 设置"** —— 想把多个站点的 Key 汇总成一个 API 地址给桌面软件用，看这里。
4. **其他区域（自动化、近期使用、配置概览）** —— 按需展开查看与跳转。

## 这一页适合谁看

- **刚装好插件**：想看"我账号加好了没、还有什么基础配置没做"。
- **日常使用**：想快速看一眼"账号健不健康、今天用了多少、有没有漏签到"。
- **出了异常**：有账号掉线或连不上时，直接从这里的警报跳过去排查。

## 如何进入

- 打开浏览器右上角插件弹窗，点击右上角 **`设置`** 进入设置页。
- 默认进入的就是"总览"；如果点了别的页面，点击左侧菜单第一项 **`总览`** 随时返回。

## 页面区域一览

整个页面自上而下包含这几个区域：

| 区域 | 主要内容 |
|:---|:---|
| **顶部状态摘要** | 4 个核心数字卡片，一眼总览全局数据 |
| **统一 API 设置** | 引导把多个账号的 Key 汇总到自建网关，统一给客户端调用 |
| **需要处理** | 优先展示需要你关注的问题（如账号失效、未配置引导） |
| **自动化执行** | 4 个自动化任务（自动签到、公告抓取等）的折叠监控面板 |
| **近期使用** | 汇总今日与近 7 天的请求数、Token、花费估算与占比 |
| **配置概览** | 6 类核心功能的配置状态，支持一键智能跳转设置项 |

## 1. 顶部状态摘要

4 个核心数字卡片，一眼看清当前整体运行情况：

| 卡片 | 含义 | 点击效果 |
|:---|:---|:---|
| **账号** | 当前已启用的账号数量 | 点击跳转到「账号管理」 |
| **凭据库** | API 凭据库中已保存的条目数量 | 点击跳转到「API 凭据库」 |
| **今日用量** | 今日所有账号调用的 API 请求总数 | 点击跳转到「用量分析」 |
| **待处理** | 需要处理的异常或待办事项数量 | **纯状态展示（不可点击）**，具体内容在下方「需要处理」区查看 |

### 状态圆点颜色含义：
- 🟢 **绿色**：正常 / 有数据。
- 🟡 **黄色**：需要留意（如账号数为 0，或"待处理"数量大于 0）。
- 🔵 **蓝色**：中性提示 / 暂无数据（如凭据库为 0，或今日暂无请求）。

> 📌 **今日用量的数据覆盖度**：
> 
> 鼠标悬停在今日用量卡片上时，会弹出气泡提示："完整 X · 部分 Y · 符合条件 Z"（如果有账号还没刷新，会标上"含待刷新"）。
> 
> 这是告诉你今天的数据是不是统计全了。详情请看 [用量分析](./usage-analytics.md)。

## 2. 统一 API 设置（自建 AI 网关引导）

> 💡 **这是干嘛的**：如果你在好几个 AI 站点买了 Key，每个聊天软件（如 Cherry Studio、ChatBox 等）都要分别填一遍，非常麻烦。
>
> 这一区会一步步引导你把分散的 Key 导入到你的 **自建 AI 网关**（如 New API / One API），对外只用一个 API 地址和密钥，所有聊天客户端只要配一次就能调用所有模型！

### 4 步进度引导：

1. **准备数据源**：添加可读取 Key 的账号，或在凭据库里手动保存 API Key。
2. **保存网关设置**：填写你自建 AI 网关的管理员连接信息。
3. **创建网关渠道**：把已有的账号 Key 或 API 凭据一键导入为网关渠道。
4. **连接客户端**：获取网关的 API 地址和调用密钥，配置到你的客户端软件中。

### 状态与按钮：
- 卡片右上角会显示当前的数据来源徽章（如 `还没有来源`、`账号来源`、`凭据来源`、`账号 + 凭据`、`账号暂不可导入`）。
- 步骤带有进度标识：✅ 已完成 / 🔵 当前步骤 / ⚪ 稍后。
- 卡片下方的按钮会随着你的进度动态变化（比如提示"添加账号"、"配置自建 AI 网关"、"添加第一个网关渠道"）。

> 💡 **不想自建网关也没关系**：如果你不需要自建网关，完全可以忽略这一块，直接在「API 凭据库」把单个 Key 复制或导出到软件里用。
>
> ⚠️ **边界说明**：All API Hub 只负责帮你在本地管理和导入配置，不代理你的模型请求。客户端聊天时是直接和你自己的自建网关通信。

## 3. 需要处理

这里只显示**需要你处理**的事项，按严重程度排序：

- 🔴 **错误**：某个账号连不上了（如登录失效、被封禁），显示 `[账号名] 状态异常` 及原因。点右侧 **「打开」** 直达该账号排查。
- 🟡 **警告**：账号有轻微异常，点右侧 **「打开」** 直达排查。
- ℹ️ **提示**：
  - 刚装好插件还没加账号：显示 `还没有账号`，点 **「打开」** 去添加账号。
  - 还没存任何 API 凭据：显示 `还没有 API 凭据`，点 **「打开」** 去录入凭据。

> 🟢 **空状态**：当没有任何需要处理的事项时，这一区会显示绿色对勾与 **`当前没有需要处理的事项。`**

## 4. 自动化执行

右侧为 4 个自动化任务的**折叠监控面板**（平时默认收起，点一下展开看详情，右侧小图标可一键直达）：

### ① 自动签到
- **展开内容**：本轮签到概况（如 `5/10` 表示 10 个可签账号中已成功 5 个）、成功/失败/跳过小方块、上次运行时间、下次计划时间。
- **操作按钮**：提供 **「查看签到」**（打开签到页）和 **「重试失败」**（仅在有失败时显示）。

### ② 网站公告抓取
- **展开内容**：抓取间隔（分钟）、公告总数、未读公告数、最近检查时间。
- **操作按钮**：提供 **「查看公告」** 和 **「设置抓取」**（跳到设置修改抓取频率）。

### ③ 托管站点模型同步
- *仅在你设置了支持模型同步的自建网关时显示。*
- **展开内容**：同步间隔（小时）、并发数、限定模型数。
- **操作按钮**：提供 **「打开同步」**。

### ④ WebDAV 备份同步
- **展开内容**：同步间隔（分钟）、同步策略（合并/仅上传/仅下载）、同步数据范围数。
- **操作按钮**：提供 **「打开备份同步」**。

## 5. 近期使用

显示今天和近 7 天的使用情况快照：

- **左侧核心花费**：以大字号显示 **今日消耗**（估算的花费金额，如 `$0.15`），提供 **「打开」** 按钮跳转到「用量分析」看详细图表。
- **中间 4 个指标格**：
  - **今日请求**：今天调用的 API 次数
  - **今日 Token**：今天消耗的 Token 总量
  - **近 7 日请求**：过去 7 天累计请求数
  - **近 7 日 Token**：过去 7 天累计 Token 总量
- **右侧近期趋势**：
  - 副标题显示 **"今日在近 7 日中的占比"**。
  - 下方展示 **2 条百分比进度条**：
    1. **请求占比**：今日请求占近 7 天总请求的百分比。
    2. **Token 占比**：今日 Token 占近 7 天总 Token 的百分比。

> ℹ️ **还没有用量记录时**：整个区域会显示一个空状态卡片，提示 *"发起一次请求或完成用量历史同步后，这里会自动汇总..."*，点"打开"可去用量分析查看。

## 6. 配置概览

按类别展示 6 张配置状态卡片：

| 类别 | 说明 | 包含子项按钮 |
|:---|:---|:---|
| **账号基础** | 账号、余额与健康状态，是其他能力的基础 | 账号管理 |
| **凭据资产** | API 凭据与账号密钥是否已经准备好 | API 凭据、API 密钥 |
| **自动化** | 自动签到与公告抓取是否处于可用状态 | 自动签到、网站公告 |
| **数据历史** | 用量与余额历史是否已有可查看数据 | 用量分析、余额历史 |
| **备份同步** | 本地数据备份与跨设备同步配置 | WebDAV 手动备份、WebDAV 自动同步 |
| **自建 AI 网关** | 自建网关的渠道管理与模型同步（配置了自建站点才显示） | 渠道管理、模型同步 |

### 🌟 贴心的“智能跳转”：
每张卡下面的子项按钮带状态徽章（已配置 / 未启用 / 待设置 / 不适用），点击时非常聪明：
- **如果这项还没配置好**：点击会自动跳转到「基础设置」对应位置，并**直接黄色框高亮**标记出那个开关，告诉你该在哪开！
- **如果这项已经配置好了**：点击就直接打开对应的业务页面（比如直接打开自动签到页面）。

## 页面加载与状态说明

- **加载中**：页面中部转圈，文字提示 *"正在加载总览..."*。
- **部分加载失败**：顶部黄色提示 *"部分信息加载失败，已显示可用数据。"*，点右侧 **「重试」** 可重新拉取。
- **数据更新**：进入总览页面时会自动刷新数据；部分用量和历史有本地缓存。

## 常见问题（FAQ）

| 问题 | 说明 |
|:---|:---|
| **为什么有些数字显示 "—"？** | 数据还在拉取中，或者当前站点不支持该项数据。等几秒刷新一下即可。 |
| **我不想看"需要处理"区，能关掉吗？** | 不能单独关闭。这里汇集的是影响插件使用的重要提醒，问题解决后会自动消失。 |
| **统一 API 设置是必须做的吗？** | 不是。如果你只是想自己记录余额或单个导出 Key，完全不需要自建网关。 |
| **"自建 AI 网关"那张卡我怎么没看到？** | 正常现象。只有当你在设置里选择了自建站点类型（如 New API 等）时它才会出现。 |
