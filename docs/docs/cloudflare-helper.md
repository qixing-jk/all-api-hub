# Cloudflare 过盾助手

> 帮助处理 Cloudflare、阿里云等已支持的网站验证页面。在操作允许、权限和设置满足条件时，插件会等待验证放行并继续安全的读取；需要人工验证时，能否继续取决于当前操作和浏览器会话。

## 功能概述

- **识别验证响应**：公共请求和登录流程识别已知验证页面及响应特征。401、403、429 或普通验证码组件本身不代表一定需要过盾。
- **按策略恢复**：允许恢复的读取可以使用适合当前账号和浏览器存储环境的临时页面。自动任务遵守总开关和功能开关，手动操作仍需满足权限和环境要求。使用独立凭据的直接请求不会自动切换到其他浏览器登录态。
- **避免重复提交**：登录、签到、生成令牌等有副作用的操作，即使使用 GET，也不会因遇盾或响应丢失而自动重放。结果不明时保留未确认状态，不能把验证放行当成业务成功。
- **登录验证接管**：密码及 OAuth 登录会先等待页面验证。持续阻挡时，在原窗口保留有期限的继续机会，并使用已配置的提醒渠道；后台窗口不会主动抢焦点。打开提醒后可在原页面处理验证，关闭窗口或取消任务会结束等待。

## 使用步骤

1. **登录目标站点**，在插件中新增账号 → 填写站点地址 → 点击“自动识别”。
2. 若操作提示正在进行网站验证，先等待页面脚本完成。出现需要人工处理的提醒时，打开对应页面并按站点提示操作。
3. 支持继续的任务会在验证后恢复安全步骤，并独立确认账号身份及操作结果。请以最终刷新、登录或签到结果为准。
4. 如果提示设置禁止、缺少权限或当前环境不支持，请查看相应设置和过盾历史；限流或普通网络错误不会无条件触发开窗重试。

## 用过盾历史排查

想知道临时页面为什么打开，或为什么没有打开，可以前往 **设置 → 数据刷新**，点击 **网站验证辅助** 标题旁的 **过盾历史**。历史在弹窗中显示，平时默认关闭。

账号的过盾相关异常提示、自动过盾受限提醒、签到结果中的验证失败或临时页面关闭提示，以及临时页面上的助手提示，也提供 **查看过盾历史** 入口。

1. 搜索站点、操作或诊断信息，也可以按处理状态筛选；搜索和筛选覆盖当前保留的全部记录。
2. 展开一条记录，查看触发操作、来源、可用的 HTTP 状态或错误码，以及临时页面是否创建或复用。
3. 若记录显示被设置或权限阻止，点击 **查看相关设置** 定位对应选项，再按需要调整。
4. 需要保留排查信息时，点击 **复制诊断详情**；要删除本机记录，可在历史右上角的更多菜单中选择 **清空历史** 并确认。

历史最多保留本机最近 **100 条**记录，只记录新发生的临时页面请求，不会补录升级前的操作。站点地址只保留来源，不保存 URL 路径、查询参数、Token、Cookie 或请求与响应正文。

**处理完成**表示该次临时页面任务返回了完成结果；账号是否恢复可用，请以刷新、签到等操作的最终结果为准。

## 注意事项

- **等待期限**：单次页面自动检查上限为 20 秒；支持人工继续的登录会话另有有限等待期限。关闭窗口会取消该次登录。
- **权限和设置**：请依据扩展显示的具体原因检查可选权限、自动过盾设置及浏览器支持情况。
- **重复限制**：429 等限流应按站点提示处理，不能用重复开窗或重新提交操作代替等待。

## 常见问题

| 场景 | 解决方案 |
|------|----------|
| 验证窗口关闭 | 查看任务结果和过盾历史，区分完成、取消、超时和环境限制。 |
| 一直停留在 “Just a moment” | 若有可继续的提醒，打开原页面处理验证；超过任务期限后查看最终结果。 |
| 操作仍报 403 | 查看验证及权限原因；若原操作已经提交，先确认结果，避免重复操作。 |
| 无弹窗但识别失败 | 查看具体错误和设置限制。直接请求、缺少权限或不符合恢复条件都可能不打开页面。 |
| 验证页面显示不全 | 在 **设置 → 数据刷新 → 网站验证辅助 → 验证窗口尺寸** 调整宽高并保存，下次新建验证窗口时生效。 |
