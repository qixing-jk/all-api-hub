# 权限管理（可选权限）

权限管理用于查看、授予和撤销扩展的可选权限。按需开启账号刷新、辅助工具、系统通知或书签导入所需的权限；未授权时，对应功能可能受限，其他功能仍可继续使用。

## 设置入口

打开扩展的 **设置 → 权限管理**，查看当前浏览器可用的权限及授权状态。不同浏览器支持的权限有所不同，以页面实际显示为准。

## 何时需要授权？

| 权限 | 用途与使用场景 |
| --- | --- |
| Cookie 访问 | 检查登录状态或刷新账号时，读取对应站点所需的 Cookie。 |
| 网络请求规则、访问或修改 | 为临时页面验证、账号刷新等流程补充当前账号所需的请求信息。Chrome、Edge 与 Firefox 使用的权限名称不同。 |
| 读取剪贴板 | 复制相关内容后，供兑换码助手或 AI API 测试识别兑换码、API 信息。 |
| 系统通知 | 通过浏览器发送后台任务结果等系统通知，还需在通知设置中选择相应事件。 |
| 浏览器书签 | 从书签导入站点时，读取已保存的网址。 |

不使用某项功能时，可以保持对应权限关闭。遇到网站验证或刷新问题时，按功能提示检查所需权限，无需为了普通刷新开启所有权限。网站验证的具体设置见 [Cloudflare 过盾助手](./cloudflare-helper.md)。

## 授予、撤销与刷新状态

1. 找到需要使用的权限，点击 **允许（推荐）**。
2. 若浏览器弹出确认对话框，确认后检查页面是否显示 **已授予**。部分权限不会弹出对话框，以页面状态为准。
3. 不再需要时，点击 **撤销**。再次使用相关功能时，可能需要重新授权。

页面显示 **检测中** 时，请等待状态读取完成。如果你在浏览器设置中更改了权限，可点击 **刷新状态** 重新读取。

## 数据保存与隐私

账号与站点配置默认保存在浏览器本地。扩展使用内置的本地存储权限（含 `unlimitedStorage`）保存配置和历史数据，无需在权限管理页单独开启。该存储权限本身不产生权限警告。

用量历史和余额历史按你在对应设置中指定的天数保留，超出保留期后自动清理；其他历史与缓存也有各自的清理规则。可用存储空间仍受设备剩余空间限制，需要备份时可使用 [WebDAV 备份与自动同步](./webdav-sync.md)。

授予可选权限并不等于开启对应功能。扩展按你使用的功能和设置访问所需数据；刷新余额、访问站点接口、备份同步或匿名产品统计等功能会产生相应的网络请求。

## 故障排查

- **点击“允许”后没有弹窗**：先检查是否已显示“已授予”。若仍未授权，留意浏览器的权限提示，并在需要使用该功能时重试。
- **权限显示“暂不可用”或缺少某一项**：检查浏览器是否支持相应权限，并尝试刷新状态。
- **已授权，但网站验证或刷新仍失败**：权限只是运行条件之一，还需检查网站验证辅助设置、站点登录状态和网络连接，参阅 [Cloudflare 过盾助手](./cloudflare-helper.md)。
