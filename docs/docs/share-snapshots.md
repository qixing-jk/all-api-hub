# 分享快照

> 将当前账号余额、用量等数据生成一张图片快照，方便分享到社区或截图留存。

## 功能概述

- **视觉快照**：生成 1200×1200 的 PNG 图片，包含总览或单个账号的余额、用量等摘要信息
- **剪贴板复制**：生成图片后自动复制到剪贴板，可直接粘贴到聊天或文档中
- **图片下载**：如果剪贴板不可用，会自动下载 PNG 文件到本地
- **标题文案**：生成图片的同时，会将快照标题文案也复制到剪贴板，方便分享时附带说明
- **敏感信息保护**：快照图片仅包含可公开展示的摘要数据，不会包含 API Key 等敏感字段

## 使用场景

- **社区分享**：将余额或用量快照分享到 Discord、Telegram 等社区渠道
- **截图留存**：生成图片保存到本地，作为账号状态的视觉记录
- **问题反馈**：在反馈或讨论中附上快照，便于他人了解当前账号概况

## 使用方法

### 分享总览快照

1. 打开扩展弹窗，在总览页标题栏右侧点击「分享总览快照」按钮
2. 插件会自动生成图片并复制到剪贴板
3. 在目标位置（聊天窗口、文档等）粘贴即可
4. 如果剪贴板不支持图片，会自动下载 PNG 文件到本地

### 分享账号快照

1. 打开「设置 → 账号管理」
2. 在目标账号的操作菜单中点击「分享账号快照」
3. 插件会生成该账号的专属快照图片并复制到剪贴板
4. 在目标位置粘贴即可

## 快照内容

| 字段 | 说明 |
|------|------|
| 应用名称 | All API Hub |
| 账号类型 | 总览（全部启用账号汇总）或单个账号 |
| 总余额 / 账号余额 | 当前币种下的余额合计 |
| 账号数量 | 总览模式下显示启用账号数 |
| 今日收支 | 当日收入、支出与净额（若已启用当日收支统计） |
| 数据时间 | 快照生成的时间戳 |

## 常见问题

| 问题 | 解决方案 |
|------|----------|
| 剪贴板复制失败 | 浏览器可能禁止了剪贴板写入，检查页面权限设置后重试 |
| 图片下载而非复制 | 当前环境不支持剪贴板图片写入，已自动改为下载 PNG 文件 |
| 标题文案未复制 | 剪贴板写入被阻止，可手动从快照标题栏复制文案 |
