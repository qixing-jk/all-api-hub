# 网页 API 嗅探与验证

> 嗅探网页上的 `Base URL` 与 `API Key` 并即时验证。支持右键菜单快速检查，以及可自定义网站范围的自动探测。

## 功能背景

在浏览 AI 社区（如 Linux.do）、Github Issue 或技术文档时，经常会遇到分享的测试 Key。传统的做法是复制 `Base URL`、复制 `Key`、打开插件、填入配置、点击验证。

**网页 API 嗅探** 功能将这一流程简化为：   
- 选中文字 → 右键「检查 AI API」 → 直接测试。
- 或者：选中或复制包含凭据的内容，插件识别后弹出确认提示。

## 核心能力

### 1. 右键菜单检查 (Context Menu)
在任何网页上选中包含 `Base URL` 或 `API Key` 的文本，点击右键并选择 **“检查 AI API”**。
插件会尝试从选中文本（或剪贴板）中提取有效的接口信息，并在当前页面内弹出一个测试浮层。

### 2. 自动嗅探 (Auto Detect)
默认在所有 HTTP/HTTPS 网页中响应选中或复制操作，检测操作涉及的内容。打开帖子本身不会触发整页扫描。
- 如果提取到疑似有效的 `Base URL + Key` 组合，页面右上角会弹出轻量提示。
- 点击提示即可打开测试对话框。
- 增强检测还可提示 Base64 编码的已知格式密钥；缺少接口网址时，可在对话框补充后再测试。选中链接时会同时读取选区内的 HTTP/HTTPS 链接地址。

### 3. 页面内置测试对话框
无需离开当前网页，即可执行以下操作：
- **自动提取**：从源文本中自动分离 `Base URL`、`密钥` 和 `API 类型`。
- **即时测试**：点击“开始测试”，插件会验证 Key 的连通性及可用模型。
- **测试方式**：选择 **`流式`**（默认）或 **`非流式`**。生成类测试按所选方式执行，失败时不会自动切换；结果及保存到 API 凭据库的验证记录会标明该方式。模型列表获取不受此选项影响。
- **获取模型列表**：一键拉取上游站点支持的全部模型 ID。
- **保存到 API 凭据库**：测试通过后，可一键将其保存到插件的 [API 凭据库](./api-credential-profiles.md) 中，方便后续复制、验证或导出到 CherryStudio 等工具。

## 配置与自定义

进入 **`设置 → 基础设置 → 网页 API 检查`** 进行如下配置：

### 1. 基础开关
- **右键菜单**：是否在浏览器右键菜单中显示“检查 AI API”。
- **自动探测**：是否在参与网站中检测选中或复制的内容。

### 2. 网站黑白名单
- **白名单**：非空时，仅命中的网页可以自动提示；为空时，未列出的网站也可参与检测。
- **黑名单**：阻止命中的网页自动提示。两张列表都为空时，默认允许所有 HTTP/HTTPS 网页。
- **重叠优先级**：同时命中两张列表时，按所选的黑名单优先（默认）或白名单优先处理。
- 长列表默认显示前三条规则及下一条的淡出预览，可分别展开和收起。输入网址可在本地预览允许或阻止的结果及原因，不会发送验证请求。

### 3. 添加和编辑规则
- 点击列表旁的添加按钮，在弹窗内输入规则；可以多行粘贴，或从浏览器标签页多选网站。每条待添加规则独立选择语法，确认添加后一次保存并去重。
- **通配符**（默认）：`linux.do` 会规范为 `*://linux.do/*`，匹配该主机；`*.example.com` 同时匹配根域及其子域。`https://example.com/private/*` 可限制协议和路径；未写端口时忽略页面端口，指定端口时必须匹配。
- **完整网址**：精确匹配完整 URL，包括查询参数和片段。可通过快捷按钮选择当前页面、整个网站或包含子域。
- **正则表达式**：使用忽略大小写的 JavaScript RegExp；不安全或无效的表达式不能保存。
- 旧的域名、路径和正则规则保留原有匹配方式；已有的空受限范围会转换为阻止全部的规则。升级时，旧版未配置范围的空白名单改为所有网站，已关闭的开关保持关闭。
- 保存需明确点击添加或保存。无效输入、保存失败或取消时会保留草稿；取消不会写入规则。列表中的编辑和删除按钮用于修改已保存的规则。

### 4. 在网页中控制本站
提示中点击 **“在此网站关闭自动检测”** 可保存当前网站的关闭选择。也可通过网页右键菜单打开检测面板，切换 **“在此网站自动检测”**。该操作不改变全局开关；最终结果仍由列表规则和重叠优先级决定，若仍被阻止，可从面板进入设置调整。手动右键检查不受自动检测的网站规则限制。

## 隐私与安全

- **本地提取**：嗅探和提取过程完全在你的浏览器本地执行。
- **请求时机**：选中或复制后的提示不会发起 API 验证请求。确认打开面板且网址和密钥完整时，面板可能获取模型列表；执行测试时会向填写的 `Base URL` 发送请求。
- **凭据保存**：只有选择保存到 API 凭据库时，才会持久保存提取到的密钥。
