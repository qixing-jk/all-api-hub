# 快速导出站点配置

> 将已录入的账号密钥或 API 凭据快速带到常用聊天客户端、编程 Agents、网关与自建托管站点，避免重复输入 Base URL、密钥与模型列表。

## 支持目标

| 分类 | 目标 | 方式 |
|------|------|------|
| 优先入口 | 自建托管站点 | 调用已配置后台的管理接口创建或更新渠道 |
| 聊天客户端 | Cherry Studio | 通过本地协议唤起客户端并填充 API 信息 |
| 聊天客户端 | Kelivo | 生成移动端导入码与二维码；桌面端需手动填写 |
| 编程 Agents | CC Switch | 生成并打开目标应用对应的导入链接 |
| 编程 Agents | Kilo Code / Roo Code | 复制配置片段或下载可导入的设置文件 |
| 编程 Agents | Cursor++ | 复制可合并到 `providers.json` 的提供商配置 |
| 网关与路由工具 | CLIProxyAPI | 通过管理接口新增或更新提供商配置 |
| 网关与路由工具 | Claude Code Router | 通过管理接口导入提供商配置 |

## 前置配置

1. **站点同步**：先在插件中完成账号识别，确保密钥列表中存在可导出的 API。
2. **目标凭据**：
   - Cherry Studio、Kelivo、CC Switch、Kilo Code / Roo Code、Cursor++：无需在扩展中配置目标凭据，按导出弹窗的说明完成导入。
   - CLIProxyAPI、Claude Code Router 与自建托管站点：先在对应设置中填写管理地址和凭据。
3. **模型列表**：若需白名单导出，可在「New API 模型同步」中预先筛选模型。

## 操作步骤

1. 打开插件 → **密钥管理**，找到任意密钥或服务凭据。API 凭据库中的每张凭据卡片也提供同样的操作区。
2. 导入自建托管站点时，直接点击操作区中当前托管站点的图标；导出到其他工具时，点击 **`导出`**，再从“聊天客户端”“编程 Agents”或“网关与路由工具”中选择目标。当前数据源不支持的目标不会显示。
3. 按目标弹窗的提示完成复制、下载、应用唤起或管理接口导入。批量处理 CLIProxyAPI 或自建托管站点时，可先勾选多个密钥，再从页面批量操作区进入预览。
4. 在目标系统中确认配置是否出现，并测试调用。

## 导出内容

| 字段 | 说明 |
|------|------|
| 站点名称 | 自动取自站点/账号备注，可在导出前修改 |
| Base URL | 使用账号的 `base_url`，确保包含协议前缀 |
| API Key | 取自密钥列表，若站点支持多密钥会逐个列出 |
| 模型列表 | 来自站点能力探测或 New API 模型同步结果 |
| 分组/优先级 | 针对自建托管站点，可在导入面板中按目标后台能力调整 |

## 常见问题

| 问题 | 处理方式 |
|------|----------|
| 自建托管站点提示 401/403 | 确认后台凭据未过期，并已在插件中重新保存配置；必要时参考 [Cloudflare 过盾助手](./cloudflare-helper.md)。 |
| Cherry Studio 无响应 | 检查是否已安装桌面端并允许浏览器唤起 `cherrystudio://` 协议。 |
| CC Switch 导入失败 | 确认已安装并更新到支持目标应用导入的版本，再重新打开导入链接。 |
| 模型列表为空 | 站点尚未返回模型数据，可先在插件内刷新模型列表或执行 New API 模型同步。 |
