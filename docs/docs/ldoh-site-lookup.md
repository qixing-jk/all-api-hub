# LDOH 站点查询

> 在账号列表中一键跳转到 LDOH 站点目录，查看对应站点的信息。

## 功能概述

- **站点跳转**：在账号管理列表中，每个站点名称右侧会出现 LDOH 图标，点击即可跳转到 LDOH 网站并搜索对应站点
- **添加账号辅助**：在新增账号对话框中，可点击"打开 LDOH 站点列表"入口，便于查找和确认站点地址
- **后台缓存**：LDOH 站点目录会在后台自动刷新，缓存有效期为 12 小时

## 为什么需要此功能

在 AI 中转站生态中，很多站点都是由社区成员运营的。通过直接跳转到 LDOH 的相关讨论，你可以：
- **查看用户评价**：了解该站点的稳定性、响应速度和售后情况。
- **获取最新动态**：发现站点是否有新的活动、模型调整或地址变更。
- **避坑参考**：如果一个站点在社区中有较多负面反馈，可以作为你使用时的参考。

## 隐私与性能

- **静默匹配**：匹配过程在后台自动执行，不会产生额外的弹窗干扰。
- **缓存机制**：为了节省网络资源，匹配索引会在本地缓存 12 小时。只有在缓存失效或手动刷新时，插件才会请求一次索引更新。
- **无需登录**：此功能仅通过公开的 URL 进行比对和搜索跳转，不要求你登录 Linux.do 账号。

## 相关说明

- **匹配不成功？**：由于社区站点层出不穷，索引可能无法覆盖 100% 的站点。如果你的站点没有显示匹配结果，这仅仅代表该地址尚未被收录到当前的 LDOH 索引中。
- **数据来源**：该功能由社区志愿者维护的 [LDOH 站点聚合 API](https://ldoh.105117.xyz) 提供支持。

## 使用方法

### 从账号列表跳转

1. 打开「设置 → 账号管理」
2. 在站点名称列右侧，点击 LDOH 图标
3. 浏览器会自动打开 LDOH 网站，并搜索对应站点

### 从新增账号入口查找

1. 在「设置 → 账号管理」点击「新增账号」
2. 在站点地址输入框附近，点击「打开 LDOH 站点列表」
3. 在 LDOH 网站上查找目标站点，记录地址后返回插件手动添加

## 数据来源

LDOH 站点查询的数据来源于 LDOH 公共站点目录服务（`ldoh.105117.xyz`），缓存于扩展本地存储中，定期自动刷新。

## 注意事项

- LDOH 站点查询仅提供跳转链接，不会自动添加账号
- 站点目录的更新由 LDOH 服务端控制，插件仅缓存和展示
- 如果 LDOH 图标未显示，说明当前站点在 LDOH 目录中没有匹配记录
