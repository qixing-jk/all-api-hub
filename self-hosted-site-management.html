自建站点管理

把插件里已有的账号接入你的自建站点，省去重复复制地址和密钥。接入之后，用自己的 API 统一调用；日常改配置、更新模型或换站点，也能继续在插件里处理。

支持的系统类型

All API Hub 深度适配了以下开源/自建 AI 分发系统：

系统类型核心管理对象特点
New API / DoneHub / Veloera渠道经典的渠道管理，支持 55+ 种上游类型，具备分组、优先级与权重体系。
Sub2API账号面向 Claude、OpenAI、Gemini、Antigravity 等订阅的统一接入与共享管理。
AxonHub渠道高性能 AI 网关，支持 15+ 种渠道类型，界面简洁，配置高效。
Claude Code Hub提供商专注于多厂商接入与弹性调度，提供商管理逻辑清晰，适配多种响应协议。
Octopus渠道面向个人的轻量级聚合服务，支持 6 种主流渠道类型。

功能概述

  • 🔑 多个账号，通过自己的 API 统一调用：连接自建站点后，在“密钥管理”里选择要用的密钥，单个或批量导入为渠道。已有的地址和密钥会自动带入，省去逐个复制填写。
  • 📋 改渠道，直接在插件里处理：要加渠道、改配置，直接打开插件里的渠道列表操作；不再使用的渠道，勾选后就能一起删除。配置了多个站点，也可以在这里切换。
  • 🔄 模型更新了，让插件帮你跟进：你可以手动同步一条或多条渠道的模型列表，也可以开启定时同步，让插件按你设定的间隔更新。同步后可以查看结果。
  • 📦 换个站点，把现有渠道带过去：选好渠道和目标站点，就能通过“渠道迁移”（测试版）复制过去。迁移前会列出能保留和需要调整的设置，方便你确认后再开始，少做一遍重复配置。

不同站点能用的功能会有区别，页面会提供相应的操作入口和提示。

配置指南

在使用管理功能前，需先在插件中完成对应后台的连接配置。

1. 进入配置页面

打开扩展设置页，在左侧菜单进入 “基础设置”，找到 “自建站点管理”。

2. 填写连接信息

配置项说明
Base URL你的自建系统后台地址（通常是网页访问地址）。
认证凭证New API 系列：需要管理员令牌 Admin Token 与用户 ID。
Sub2API：管理员 API Key（读取密钥需要额外网页验证时，插件暂无法查看、导出密钥或将渠道迁出）。
AxonHub：管理员邮箱与密码。
Claude Code Hub：管理员邮箱与密码。
Octopus：用户名与密码。

3. 验证连接

点击 “验证配置”。验证成功后，对应系统的管理入口将自动解锁。

渠道管理操作指南

1. 列表操作

在设置页面顶部选择 “自建站点管理”（或直接点击基础设置里的 “管理渠道”）：

  • 搜索与过滤：支持按名称、类型、状态进行实时搜索。
  • 快速切换系统：如果你配置了多个自建系统，可以通过顶部的切换器快速跳转。
  • 自定义列：对于不支持“优先级”或“权重”的系统（如 Octopus），对应列会自动隐藏。

2. 创建或编辑渠道

  1. 点击右上角 “新增渠道”。
  2. 表单会自动根据当前系统类型调整：
    • New API: 提供丰富的渠道类型和分组配置。
    • Claude Code Hub：需选择提供商类型（OpenAI Compatible、Claude、Gemini 等）。
    • AxonHub: 支持快速配置模型列表。
  3. 点击保存后，系统会直接调用后台 API 完成同步。

3. 安全验证（2FA / OTP）

当执行敏感操作（如查看渠道真实密钥）时，如果系统开启了二次验证，插件会弹出验证窗口。

  • 详情请参阅：New API 安全验证

4. 渠道迁移（测试版）

将当前自建站点的渠道复制到另一个已配置的站点，省去逐条重建渠道。请先完成来源和目标站点的连接配置。

  1. 在来源站点的渠道列表页开启 “渠道迁移”，选择要迁移的渠道或使用当前筛选结果。
  2. 选择目标站点，查看迁移预览中的类型、地址、模型、分组和状态，以及无法保留的设置。
  3. 点击 “开始迁移” 并确认，插件会读取源渠道密钥并在目标站点创建渠道。
  4. 核对每条迁移结果。出现 “状态不确定” 时，先刷新列表并检查目标站点，再决定是否重试，避免重复创建。

迁移只创建新渠道，不会修改来源、查重、覆盖已有渠道或自动回滚。

不同系统支持的渠道类型和配置项不同，请以迁移预览中的状态与提示为准。分组、模型映射、优先级等设置可能会调整或无法保留，迁移后请在目标站点核对渠道配置和启用状态。

若提示需要验证才能读取来源密钥，请完成验证后重试；当前验证方式不受支持时，可从来源后台获取密钥，手动添加到目标站点。

常见问题

问题解决方案
配置验证失败请确认 Base URL 是否填写正确（是否带 https://），以及管理员权限是否有效。部分系统要求关闭两步验证或使用特定的 API 令牌。
列表加载缓慢当渠道数量较多时（>100个），受限于后端 API 性能，加载可能需要几秒钟，请耐心等待。
无法同步模型请确认自建站点的后端网络是否可以正常访问上游地址（如 OpenAI / Claude 官网）。
某些字段显示 Unknown这通常是因为自建站点的版本过新或过旧，返回了插件尚未适配的类型 ID。
