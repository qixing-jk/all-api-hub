All API Hub - Your All-in-One AI Asset Manager

An open-source browser extension for AI relay accounts and API credentials, with management for self-hosted gateways such as CLIProxyAPI, New API, and Sub2API. Check balances, compare model prices, verify APIs, and back up with encrypted WebDAV.

📊 Multi-Site Asset Dashboard

See balances, usage, trends, and account status across multiple AI relay sites on one screen instead of managing them separately.

🔑 API Credential Library

No site account required—keep Base URLs and API Keys shared by others or collected over time in one place, ready for lookups, testing, or export.

💰 Cross-Site Model Price Comparison

Calculate effective model prices across sites and quickly find better-value models and groups.

✅ Multi-Site Auto Check-In

Run daily check-ins for supported accounts with one click or on a schedule, collect rewards automatically, and skip daily logins.

🧪 API, Model & CLI Verification

Test API connectivity, model availability, and CLI integration in one click to quickly troubleshoot configuration issues.

🔔 Announcements & Task Alerts

See announcements from added sites in one place and receive timely maintenance, model, and pricing updates, plus results from scheduled background auto check-ins, WebDAV auto-sync, and model sync.

🚀 Web Capture & One-Click Export

Quickly find Base URLs or API Keys on web pages and export them to popular AI clients with one click.

🛠️ Popular AI Gateway Support

Manage CLIProxyAPI, New API, Sub2API, AxonHub, Claude Code Hub, Octopus, Veloera, and DoneHub in one place; quickly add site configurations from saved accounts or API credentials, with model sync and redirects where supported.

🔐 Local-First Storage & Auto-Sync

Data stays in your browser by default; enable encrypted WebDAV auto-sync to keep it safely synchronized across devices and continue where you left off after switching computers.

Introduction

In the AI era, many of us keep multiple relay-site accounts to save money or try different models. Managing them quickly becomes painful: balances are scattered, pricing is messy, and daily manual check-ins are easy to miss.

All API Hub is built to solve those problems. It is your AI asset center, making management simpler, clearer, and more automated.

🎯 Use Cases

👤 I am a regular AI user (recommended for beginners)

  • How do I start?: Download and install the extension -> Add my first account
  • I want to save money: Earn credits with auto check-in -> Compare model prices across sites
  • I want less manual work: See asset changes at a glance -> Sync accounts to other AI tools -> Receive background task notifications

🛠️ I am an advanced user (Key collector)

  • Key management: Save standalone URL+Key pairs to the API Credential Library
  • Availability testing: Batch verify API and CLI compatibility
  • Cross-device sync: Configure encrypted WebDAV backup

👑 I am a site admin (operator area)

  • Efficiency tools: Manage channels inside the extension -> Batch sync models
  • Configuration optimization: Set up model redirection
  • Security safeguards: Handle 2FA / OTP verification

🧩 Supported Site Architectures

No matter which architecture you use, there is a good chance we support it:

  • Account-site compatible architectures: New API, One API, Sub2API, One-Hub, Veloera, Done-Hub, and more.
  • Specialized account platforms and compatible implementations: OpenRouter, AnyRouter, AgentRouter, AIHubMix, Super-API, v-api, Neo-API, and more.
  • Self-hosted admin backends: CLIProxyAPI, New API, Sub2API, AxonHub, Claude Code Hub, Octopus, Veloera, DoneHub, and more, for backend management, with migration and model sync where supported.
