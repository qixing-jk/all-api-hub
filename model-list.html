模型列表与价格比对

模型列表用于读取、筛选、比较和验证当前数据源提供的模型目录。页面汇总不同账号和 API 凭据中的模型、价格与可用性信息，并按当前已加载且可比较的数据，帮助你结合实际使用场景选择模型与来源。

功能概览

  • 🔍 三类数据源：所有账号、指定账号、API 凭据（API Credential Profile）。
  • 💰 跨账号价格比较：把不同账号中的同一模型放在一起，按统一口径比较当前可用报价。
  • 🎯 贴近用量的估算：可选择普通对话、代码补全、编码 Agent 等使用场景，也可以自行调整输入、输出和缓存占比。
  • 🏷️ 搜索、筛选与排序：按模型名称或描述搜索，按厂商、计费方式、能力、分组、验证结果筛选，并按价格、延迟等排序。
  • ✅ 模型验证：支持单项探测、常规测试和批量验证，用于判断模型或接口当前是否可用、是否兼容 CLI。文本模型的常规测试会运行多项探测，付费接口可能产生调用费用。
  • 📦 模型对应密钥：为模型选择兼容的密钥，或在能力允许时创建限制到该模型的 Token。

进入方式

  1. 在扩展弹窗点击 模型列表 图标。
  2. 打开完整标签页，在左侧 接口 分类下进入 模型列表。
  3. 在账号管理或 API 凭据库中，也可通过 在模型列表中打开 直接进入。

核心操作指南

1. 选择数据源

在页面顶部的 选择数据源 下拉框中切换数据源：

  • 所有账号：聚合已添加的全部站点账号，用于跨站比较。
  • 指定账号：查看某个账号的模型目录。
  • API 凭据：使用 API 凭据库中保存的 Base URL + API Key 读取模型目录（无需创建站点账号）。

“提供商目录 / 个性化目录”是某些账号内部的数据范围说明，不是顶部独立的数据源选项。

不同数据源能提供的信息不同：

数据源价格/倍率/分组说明
所有账号视各账号能力用于聚合比较
指定账号视适配器而定部分来源提供价格、倍率、分组；部分只有模型目录
API 凭据一般不提供主要用于模型发现与验证

提供商公共目录描述站点公布的模型和价格，不保证某把密钥或某个套餐可用。只有数据源支持密钥匹配与验证时，页面才提供相应操作。

目录价格可能只覆盖部分计费条件；分组、长上下文、图片等规则请通过官网入口核对。已包含在展示价中的折扣不会重复计算；无法确定计费含义的零值不会按免费处理。

2. 搜索、筛选与排序

  • 搜索：匹配模型 ID、显示名称和描述；不按站点名称搜索。
  • 厂商标签：按解析出的厂商分类查看（含“未分类”）。
  • 计费方式：全部 / Token（按量）/ 按次。
  • 模型能力：图片、音频、视频、PDF、推理、工具调用、结构化输出等（仅在来源提供能力说明时出现）。
  • 分组筛选：按账号分组过滤；所有账号视图下可按账号分别选择参与比较的分组。
  • 测试结果：成功 / 失败 / 未测试。
  • 排序方式：默认顺序、价格从低到高、价格从高到低、测试延迟从低到高；所有账号视图下还有“同模型最低价优先”。
  • 价格比较条件：在价格排序下选择使用场景，或自行调整输入、输出、缓存读取和缓存写入占比。
  • 显示内容：真实充值金额、端点类型。

筛选和排序控件只在当前来源支持时出现；不要假设每个来源都有全部控件。

3. 比较价格

点击 一键比价 会清空当前筛选、切换到所有账号，并按同模型最低价优先排序。

  • 设置比较条件：先选择使用场景或调整输入、输出、缓存占比。遇到阶梯或条件价格，再按提示填写输入、输出长度或图片尺寸等适用条件；长度用于选择价格档位，不代表本次请求的用量。
  • 查看可比较报价：相同计费单位、且满足当前条件的完整报价才参与比较。提示缺少条件时先补充；价格信息不全的报价会说明原因，不会按免费处理。
  • 核对价格明细：留意报价标注的单位，如每 100 万 Token、每张、每秒或每次；不同单位分别比较。展开模型可查看价格明细和各分组报价。

价格标签可以这样理解：

  • 普通价格：站点明确提供的单价或计费规则直接展示，不额外添加精度标签。分组、阶梯、时段等适用条件单独说明。
  • 已换算：按当前汇率转换显示币种，原币种价格不变。
  • 估算价：根据参考费率、分组倍率或积分折算等假设推算；实际账单仍以服务方为准。
  • 最低价：当前筛选与比较条件下，可比较报价中的最低选项。
  • 最优组：可比较分组中只有一个分组价格最低时显示；如果最低价并列，则不会指定其中一个。
  • 价格比较是本地计算，只覆盖当前已加载、价格有效且口径可比较的数据；它不是官方承诺、实时全量数据或“全网最低价”。
  • 缺失或非法的价格不可比较，不会按 0 或默认价格处理；站点明确提供零价时，该模型可能确实免费。
  • 价格来源可能不同（如站点定价接口、官方目录、估算值），页面会尽量标明来源与精度。

原生额度计费：模型列表可独立展示和估算 Token、积分等非货币额度，并按同一资产和允许的来源范围排序；不会将同名额度或不同站点的余额自动视为等价。参考消耗缺少额外倍率时，仅用于来源内的基础消耗排序，不代表最终扣费或跨站最低价。

EMRank 使用 Token 额度，1 M Token = 1,000,000 Token。与货币价格使用相同的输入、输出费率布局，按每百万模型 Token 展示；输出费率为零。默认显示公开费率，价格排序时才显示用于排序的参考消耗，并复用现有用量权重设置。等级、RPM 等附加倍率可在计费规则提示中查看；未知倍率不默认按 1 计算，参考值不代表最终扣费。原生额度不换算为美元或人民币。详见 EMRank 计费与额度。

模型行显示用途、站点可用状态和已提供的上下文长度；展开详情可查看目录归属、支持及默认向量维度、图片支持和发布日期。未提供的规格不会推断填充。调用示例链接前往官网模型页；嵌入、重排和决策模型不显示不适用的文本生成或 CLI 验证入口。

4. 分组切换与最优组

如果一个来源支持多个用户分组，可以在分组筛选中限定参与比较的分组，并展开模型查看各分组价格。分组会直接影响实际单价；准备使用某个报价前，请确认账号确实可以使用对应分组。

“最优组”是当前筛选和比较条件下的本地计算结果，不是服务商官方推荐或长期保证。

5. 单模型验证

点击模型卡片的验证图标：

  • 测试 API：打开测试弹窗，运行单项探测或常规测试，确认该模型或接口当前是否可用、返回是否符合预期。
  • CLI 兼容性测试：评估该模型是否适合 CLI 工具（如是否支持流式输出、文本生成等）。

在 API 测试 弹窗的 测试方式 中选择 流式（默认）或 非流式。生成类测试按所选方式执行，结果和新保存的历史记录会标明使用的方式。接口拒绝请求时，可以切换方式重测；测试不会自动切换。模型列表获取不受此选项影响。

CLI 兼容性测试 是打开同一 API 测试 弹窗的快捷入口，会预选客户端模拟。你仍可选择客户端、接口类型，以及 流式（默认）或 非流式；结果会标明测试方式，失败时不会自动切换。

  • 单项测试只运行所选探测；文本模型的常规测试会运行多项模型探测。结果不代表长期真实可用，也不代表永久失效。
  • CLI 兼容性测试不会启动真实外部 CLI，只做协议级模拟检查。

6. 进阶验证：绘图测试与提示词

普通验证历史仅保留状态、摘要与耗时，重新打开后不提供未保存的原始输入输出。绘图测试对已保存的账号/凭据按模型保存运行摘要（产物状态、时间、耗时和调用计数），并沿用验证历史的清理规则；SVG、Agent 文件和调用明细仅保留在当前会话，重新打开时会明确提示仅恢复摘要。未保存凭据的网页测试仍不持久化。

验证弹窗的参数保留在正文，以紧凑网格排列；顶部结果说明与已有验证摘要放在弹窗标题区，不单独占用提示色块。每项测试的 编辑提示词 与 执行结果 分开展示，执行完成后自动打开结果；文本回复直接显示，输入参数和原始输出可按需展开。编辑器显示当前实际提示词，切换查看结果不会丢失未保存的修改。测试只反映当前接口、模型和请求配置，不保证完整兼容。

测试 API、CLI 兼容性测试 与网页 API 测试弹窗都直接展示**绘图测试**卡片，无需展开进阶区域。绘图仅在点击运行按钮后执行，不随 运行常规测试 或批量测试执行，因为每次都会产生真实的模型调用。

绘图测试 要求模型画一只骑自行车的鹈鹕 SVG，便于直接比对画风与结构；结论由你自己判断。弹窗只负责提取 SVG、统计形状数量，并在回答包含脚本或外部引用时阻止渲染。

单次回复与 Agent 模式共用默认用户提示词 Generate an SVG of a pelican riding a bicycle，自定义提示词也共用。Agent 模式通过独立的系统说明提供工作区能力及本次任务的文件交付约定，不向用户提示词追加绘图要求。

默认采用单次回复。开启 Agent 测试模式 后，模型可在本次测试的虚拟工作区列出、读写和修改文件，并执行 JavaScript（支持顶层 await 与 Promise），自行检查和修正作品。没有固定轮数或工具次数上限，运行至模型结束或你手动停止；多轮调用可能消耗更多 token。最终产物从 pelican.svg 读取，弹窗展示轮数、工具记录、工作区文件和耗时；未生成目标文件时不会自动改用最终回复。

这是基础测试环境：文件只在本次运行中共享，不访问真实文件、浏览器、网络或 Node API。支持绝对虚拟路径、相对路径及中文文件名，不限制文件数量或单段代码长度。JS 默认预算为 5 秒、128 MiB，可通过工具参数 timeout_ms（最多 60 秒）、memory_mb（最多 1024 MiB）调整；工作区保护预算为 64 MiB。日志和返回值超过各自 64 Ki 字符时只截断反馈并标记，不会中断任务或丢弃文件。JS 每次执行使用新的全局环境，成功后才提交文件修改。它不提供终端、npm 或完整 CLI 环境，也不会自动判断绘图质量。

各测试卡片内的 编辑提示词 可以修改该项验证发出的提示词（文本生成、结构化输出、工具调用、联网搜索、向量嵌入、图像生成、视频任务），展开后显示默认值，也可单项恢复默认：

  • 停止编辑后自动保存，对所有验证入口生效，包括账号验证、API 凭据验证、网页 API 验证与批量测试。绘图测试直接使用当前编辑的提示词；其他测试使用已保存的提示词。保存失败时会保留编辑内容并显示错误。
  • 留空即使用内置默认值，重置是真正的删除而不是写入空串，因此日后默认值更新仍会跟随。

提示词保存在偏好设置里，不会写进遥测；导出或同步偏好设置时可能包含这些提示词。

7. 批量测试

点击工具栏的 批量测试 打开 批量测试模型 弹窗：

测试方式 默认为 流式，也可以选择 非流式。本轮所选的生成类测试使用同一种方式，各项结果会标明使用的方式。

  1. 选择 测试项目（可按接口类型自动识别，或选择文本生成、工具调用、结构化输出等）。
  2. 在 执行模型 中勾选或全选要测试的模型。
  3. 点击 开始批量测试；测试会排队运行（最多并发 5 个），可以随时 停止测试，并保留已产生的部分结果。
  4. 弹窗会显示总计、通过、失败、跳过的数量。

不适用的测试项目会自动跳过；结果是当时的探测结果，仅供参考。

8. 模型对应密钥

点击模型卡片的密钥按钮，打开 模型对应密钥：

  • 为当前模型选择兼容的密钥（仅列出分组或能力匹配的密钥）。
  • 在能力允许时，可以为模型 快速创建 一个带模型限制的新 Token，或使用 自定义创建。

该操作修改的是“密钥/Token”，不会编辑模型目录本身。

9. 刷新数据

点击 刷新数据 会重新请求当前数据源，并使相关本地缓存失效。不同来源的刷新行为略有不同；刷新后的数据以来源返回为准。

功能边界

  • 模型列表不提供对远端模型的新增、编辑、删除、启用或禁用、批量同步。
  • 自建站点的模型同步属于独立功能，请参阅 Managed Site 模型同步。

常见问题

问题说明
为什么有的模型价格为 0 或无法参与比较？站点明确提供零价时，该模型可能确实免费；价格数据不完整时，页面会将其标为不可比较，而不会当作免费报价。
跨站比价是怎么计算的？价格比较基于当前已加载、价格有效且口径可比较的数据做本地计算；来源和精度以页面标注为准，实际费用以各站点公布价格为准。
为什么报价显示“未参与当前条件比较”？当前比较条件需要的某项价格（例如缓存读取价）没有由价格来源提供。你可以改用其他使用场景或调整占比，也可以展开报价查看现有价格。
为什么验证结果显示失败或未知？单项测试运行所选探测，文本模型的常规测试运行多项探测，付费接口可能产生调用费用。结果可能受权限、模型限制、频率限制等影响，请以工具实际调用情况为准。
为什么我的账号没有价格或倍率？该来源可能不提供价格、倍率或分组数据（例如 API 凭据只提供模型发现与验证）。
